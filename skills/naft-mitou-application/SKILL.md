# NaFT 未踏ADV応募スキル

## 使うとき
応募フォームの各設問回答／プレゼン資料の構成／面接想定質疑の準備／説明文の長さ違い派生（docs/mitou-advanced-concept.md §7 が正本）。

## 手順
1. **事実ベースで書く**: 実装済み事項は「8ロール・30画面超・テスト46項目・単一HTML PoC・Solidity雛形（未接続）」の範囲を超えて誇張しない。未実装は「未踏期間の計画」として明確に区分する。
2. **審査観点への対応付け**（各設問でこの4点を必ずカバー）:
   - 新規性: プロトコル統合／compliance-by-design／HITL審査（concept §4 の言い換え）
   - 実現可能性: 動くPoC＋テスト＋ロードマップ（roadmap.md のPhase表を引用）
   - 社会的インパクト: 「脱炭素の担い手を専門家から地域社会全体へ」
   - 本人の遂行能力: PoCを一人称で説明できる実装事実を列挙
3. **リスクの正直な開示**: 法務レビュー前であること、換金性を持たせない設計であることは隠さず、legal-risk-map §3 のゲート設計を「リスク管理能力の証拠」として提示する。
4. **文字数調整**: §7 の 200/409/1052字版を基点に増減。削る順序: 波及効果→実装状況の詳細→新規性の3点目。**課題とHITLの記述は最後まで残す**。
5. **文言検査**: 完成稿を skills/naft-legal-risk-review にかける（「投資」「利回り」等の混入防止）。

## 想定質疑の型
concept §8 の3問を基点に、「なぜ今か」「なぜあなたか」「実証地域の当て」「未踏費の使途」への回答を、roadmap のKPIと結びつけて用意する。
