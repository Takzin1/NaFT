# NaFT P47｜山梨県農耕地土壌GIS：原本検証・JCODE/GUNの照合保留

2026-11-10にユーザー提供`山梨県.zip`をオフラインで直接解凍し、Esri Shapefileの**564件**の図形・属性と構成7ファイルを検査。北海道・東北・関東・北陸に続く県別収録の19件目。原本の市町村コードと郡名を、自動補正せず要照合として研究台帳に保存する。

## 原本ZIPと再現性

- 提供名：`山梨県.zip`、サイズ **3,411,194 bytes**、SHA-256 `78df028c3de6bd2e4544cd12f6f7aca98aa5a9af7de60b1bd574a4fa1c5f1842`。
- ZIP内フォルダは`k15山梨県`、日本語名はCP932符号化。Shapefile関連の`.dbf`、`.prj`、`.sbn`、`.sbx`、`.shp`、`.shp.xml`、`.shx`の7ファイル、展開後**5,546,850 bytes**。個別SHA-256は研究台帳JSONに固定。
- 原本Esri POLYGON（shapeType=5）、JGD2000（GCS_JGD_2000）。SHP図形数、SHXの索引件数、DBF属性数はすべて**564件**で一致。ZIPの7構成ファイルの各バイトハッシュを検査した。
- 経度・緯度bbox：`[138.23930161753367, 35.18602299506912, 139.12879005173434, 35.948501229692546]`。DBF`KEN_1`は564件すべて山梨県、`SICHO`はすべて空欄。
- XMLメタデータ作成日**2017年1月17日**。これは個々のポリゴンの測量日、2026年の農地現況、行政コードの制度年を示すものではない。

## JCODEと市町村名の不整合

- 原本の市町村名は**27種類**、JCODEは**28種類**、JCODE×名称は**54組合せ**。14コードが複数名称、17名称が複数コードに対応する。
- 山梨県「19」ではなく**神奈川県「14」系JCODE `14151`／上野原市が1件（普通畑）**。県外コードのある原因はまだ未確認。
- 原本の値を無断修正せず、`UNRESOLVED_ORIGINAL_KEPT_NO_CITY_JOIN`。行政コードの年代と自治体境界・原本の作成経緯を確認するまで、他資料への無検証なJOINを行わない。

## GUN（郡名）と市町村名の複数対応

- GUN空欄**396件**、郡名あり**168件**。郡名付き内訳は南巨摩郡75、南都留郡41、西八代郡28、中巨摩郡14、北都留郡10。
- 郡名×市町村名は**35組合せ**。同名の市町村に郡名付きレコードがある一方でGUN欄が空欄のレコードが**計21件**：富士川町4、富士河口湖町1、市川三郷町4、忍野村1、昭和町9、西桂町2。
- **富士川町と身延町**には、「南巨摩郡」と「西八代郡」の両方が原本に記録されている。特に西八代郡は富士川町**1件（普通畑）**、身延町**3件（田1・普通畑1・樹園地1）**。過去の境界やGIS来歴との関係を確認するまでは誤りとも断定しない。
- 市町村の名称が同じでも、元属性を無断で「正しい郡名」に置き換えない。`UNRESOLVED_ORIGINAL_KEPT_NO_GUN_JOIN`として保留する。

## P47実装と再実行

- `research/p47-yamanashi-soil-shapefile-source-v1.json`：元ZIPと全7ファイルSHA、54 JCODE×名称、35 GUN×名称、分類と原本属性の不整合。
- `scripts/p47-yamanashi-soil-audit.py`：標準ライブラリだけで元ZIPのSHA、7ファイル、SHP/SHX、DBF全564件の値を再監査する`verify`と公開CI向け台帳`audit`。
- `src/gx-yamanashi-soil.js`：NaFT GX Data Atlasで山梨県選択時のみ、地目別カード、神奈川県系コード警告、郡名の混在と欠落を含む詳細表を表示。
- `tests/p47-yamanashi-soil-gis.test.mjs`：原本ハッシュ、集計、県外JCODE、21件の空欄、郡名混在、UI、既存18都道府県の回帰を検証。

原本ZIPをローカル保持する環境での検証：

    python3 scripts/p47-yamanashi-soil-audit.py verify '/local/private/山梨県.zip'

原本バイナリを持たない公開CIでの台帳監査：

    python3 scripts/p47-yamanashi-soil-audit.py audit
    node tests/p47-yamanashi-soil-gis.test.mjs

**CIのaudit成功は原ZIPの全バイト再照合成功を意味しない**。初回受け入れ時には別途実際の元ZIPを開き、各ファイルのSHA・SHP・DBF属性を確認した。

## 元資料候補・権利・研究上の境界

原資料の配布元候補は農研機構「日本土壌インベントリー／農耕地包括土壌図」https://soil-inventory.rad.naro.go.jp/download5.html 。公式配布の山梨県ZIPと今回の原本ZIPの**バイト単位SHA一致および具体的な再配布ライセンス適用は未確認**。

元Shapefile/DBF/ZIPはGitHubの公開リポジトリにコミットせず、SHA・出典候補・派生件数・検証コードだけを公開する。農地面積、土壌炭素、CH₄排出量、CO₂e削減量、J-クレジット認証をこの集計から算出しない（`official_credit_tco2e=null`）。
