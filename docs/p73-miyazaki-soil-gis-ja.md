# NaFT P73｜宮崎県農耕地土壌GIS：原本監査・行政属性の要照合・安全な再利用

## 原本ZIPの来歴・公開範囲

2026-11-10提供の `宮崎県.zip`（10,600,644 bytes、SHA-256 `2d2bd2bf4a29927698cc550c04850b850dd3aa5cf3f8ab357af2f6ad08024f51`）。`k45宮崎県` 内のDBF/PRJ/SBN/SBX/SHP/SHP.XML/SHX計7ファイル（展開計16,035,814 bytes）。SHP・SHX・DBFはすべて**756件**で一致し、全756件のレコード番号・オフセット・長さも整合。ESRI POLYGON（shapeType 5）、GCS_JGD_2000。元XMLの作成日は2017-01-17。

出典候補：農研機構「日本土壌インベントリー」 https://soil-inventory.rad.naro.go.jp/download5.html 。公式ZIPとのバイト同一性、発行者認証、再配布許諾は未確認。**原本ZIP・SHP・DBF・個別地物座標は公開GitHubへアップロードしない**。元ZIPと7構成ファイルのSHA-256、非座標の派生集計、検証手順のみを保持する。

## 原本行政属性の要照合

- 原本の全756件でKEN_1は「宮崎県」、SICHOは全件空欄。市町村名26種類、JCODE27種類、JCODE×市町村名53組、GUN×市町村名36組。
- **熊本県系JCODE `43428` が4件**（高千穂町：田2・普通畑1・牧草地1）。県内コードに無断で補正しない。
- JCODE12種類が複数名称、名称16種類が複数JCODEに対応。現在の行政区・自治体統計への自動JOINを保留する。
- **郡名GUN空欄438件**。同一市町村名に郡名があるレコードも存在するものは57件。原本を無断で補完しない。
- **熊本県系の郡名「阿蘇郡」4件**（高千穂町：田2・普通畑1・牧草地1）。高千穂町の原本には「西臼杵郡」と「阿蘇郡」の2つの郡名がある。県外系のレコードを行政統計に自動合算しない。

## 監査スクリプトと表示

- `research/p73-miyazaki-soil-shapefile-source-v1.json`：ZIP・7ファイルのSHA-256・サイズ、地目別・行政属性ペアの派生集計、コード・郡名の要照合内容を保持。
- 公開CI：`python3 scripts/p73-miyazaki-soil-audit.py audit` と `node tests/p73-miyazaki-soil-gis.test.mjs`。原本ZIPはCIに配置しないため、公開CIは台帳の整合性のみを検査する。
- 許諾済みローカル環境：`python3 scripts/p73-miyazaki-soil-audit.py verify /private/宮崎県.zip`。ZIP全体・7ファイルSHA、SHP/SHX全756レコード、DBF全756行のCP932属性と派生集計を再現検証する。
- GX Data AtlasはprefCode `45` で地目カード、JCODE×市町村名53組、郡名×市町村名36組と要照合警告を表示する。

**科学・制度的制限**：ポリゴン数は農地面積ha、土壌炭素量、CH₄排出・CO₂e削減量、認証済み炭素クレジット数ではない。圃場単位のMRVには適法な境界、年代・適用方法論、一次証拠、HITL、第三者検証が別途必要。
