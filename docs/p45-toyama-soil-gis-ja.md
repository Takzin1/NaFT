# NaFT P45｜富山県の農耕地土壌GIS：原本検証と行政コード・郡名の欠損

2026-11-10、ユーザー提供の `富山県.zip` を原本バイトから展開し、ESRI Shapefileの図形・属性、地目別内訳、JCODE×市町村名、GUN×市町村名を監査。**原データの属性を書き換えない**研究用集計としてNaFT GX Data Atlasの富山県ビュー（P45）に追加する。

## 原本の再現性と配布条件

- 元ZIP：**4,675,546 bytes**、SHA-256 `fbbe882b713db76fc18fde6106cdbaeb2a82a2302e97b1cb8dc33b1d8cc19ab7`。
- ZIP内フォルダ：`k19富山県`、7構成ファイル：`k19富山県.dbf`、`.prj`、`.sbn`、`.sbx`、`.shp`、`.shp.xml`、`.shx`。展開後の合計**7,481,198 bytes**。各サイズとSHA-256は台帳JSONへ記録。
- 元ZIPの日本語ファイル名はCP932で読み取る。原本ハッシュと構成員SHAは直接原ZIPから算出。配布元候補は農研機構（NARO）「日本土壌インベントリー／農耕地包括土壌図」：https://soil-inventory.rad.naro.go.jp/download5.html 。**今回のZIPと公式配布ZIPのSHA一致を確認していない**。ライセンス・再配布適用関係は`NOT_VERIFIED`。
- Esri Shapefile POLYGON（shapeType=5）、JGD2000（GCS_JGD_2000）、SHP・SHX・DBFともに**632件**。受入時、全図形と属性を実際に読み込み済み。
- 原本bbox（経度・緯度）：`[136.78498869633378, 36.34960657076776, 137.65754674358115, 36.97336380774928]`。
- 全632件の`KEN_1=富山県`、`SICHO`は空欄。原本XMLのメタデータ作成日は2017-01-17。作成日は現況調査年や2026年の耕作状況を保証しない。

## 地目・土壌種別

| 地目区分 | ポリゴン件数 |
|---|---:|
| 田 | 428 |
| 普通畑 | 116 |
| 牧草地 | 18 |
| 樹園地 | 70 |
| **合計** | **632** |

土壌の`群コード`は15種類、`包括_統群`は59種類。ポリゴン件数は**面積ha、地筆数、農家戸数、CH₄・土壌炭素の実測値、CO₂e認証量ではない**。

## 行政コード（JCODE）と名称の不整合

- JCODEは全件富山県の接頭`16`。**県外JCODEは0ポリゴン**。
- JCODE **15種類**、市町村名**15種類**、コード×名称の組合せは**36通り**。この二つは1対1ではない。
- **10種類のJCODEが複数名称に、12種類の市町村名が複数JCODEに対応**。例えば`16201`には富山市のほか上市町・射水市・滑川市・砺波市・立山町・舟橋村も含まれる。
- 原本の全36組合せと地目4分類件数を台帳化し、現行市町村の行政コードや別の統計との無検証のJOINは行わない。県外コード0件でも、各自治体コードが最新または一意に正しいと判断しない。

## 郡名（GUN）の欠損・表記の保持

- `GUN`が空欄は**495件**、`中新川郡`87件、`下新川郡`50件。郡名付きは計137件。
- GUN×市町村名の**19組合せ**を地目別に保持。
- 原本の同じ市町村名には郡名付き行があるのに、以下の空欄行もある。**上市町15件（中新川郡）、入善町5件（下新川郡）、立山町1件（中新川郡）、舟橋村4件（中新川郡）＝合計25件**。
- これは原本で郡名が空欄であることを意味する。GPS境界や郡名の年代を照合するまでは、**空欄25件を自動補完しない**。既存の郡名が間違っていると断定するものでもない。

## NaFTへの組込み

- `research/p45-toyama-soil-shapefile-source-v1.json`：元ZIP・全7構成ファイルのSHA256とサイズ、632件、36 JCODE×名称組合せ、19 GUN×名称組合せ、25件の郡名空欄、科学的利用制限。
- `scripts/p45-toyama-soil-audit.py`：元ZIPの全バイト・全メンバSHA、SHP/SHX全632レコード・DBF全属性を再照合する`verify`。CIでは生GISを保持せず、台帳整合性の`audit`のみ。
- `src/gx-toyama-soil.js`：GX Data Atlasの「富山県」で4地目・コード異常の保留理由・GUN空欄25件・36+19詳細組合せを表示。
- `tests/p45-toyama-soil-gis.test.mjs`：原本台帳・コード名称異常・郡名欠損・UI出し分け・既存16都道県回帰をテスト。

元ZIPがあるローカル環境で全件再照合：

    python3 scripts/p45-toyama-soil-audit.py verify '/private/local/富山県.zip'

公開CIで実施する台帳のみの監査：

    python3 scripts/p45-toyama-soil-audit.py audit
    node tests/p45-toyama-soil-gis.test.mjs

公開CIの`audit`が成功しても、**ZIP原本の全バイト比較をCIで行ったという意味ではない**。初回受入時には別途ローカルで元ZIPを直接検査した。

## 科学的・再配布上の境界

再配布権限が未確定のため、**生Shapefile・DBF・ZIPは公開GitHubにコミットしない**。公開対象はSHA256、原本属性に基づく派生件数とテスト、検証方法のみ。

現行の農地面積、CH₄排出、土壌炭素やCO₂e、認証済みJ-クレジット量をこの図形件数から推定・認証しない（`official_credit_tco2e=null`）。外部の統計やJAXA地図へのJOINは別途位置・境界・年代の照合が必要。
