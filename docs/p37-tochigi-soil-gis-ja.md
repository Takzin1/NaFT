# NaFT P37｜栃木県の農耕地土壌GIS：原本検証・JCODEと市町村名の不整合を保留

ユーザー提供 `栃木県.zip` を2026-11-09に受け入れ、原本ZIP、全7構成ファイルのSHA-256、SHP・SHX・DBFの図形/属性、地目・土壌分類・行政コード・市町村名を検査した。関東第2弾。**行政コードによる自治体別の正式な集計や地域統計との自動結合は現時点でできない。**

## 原本の来歴

- 元ZIP：13,379,287 bytes。SHA-256：`780db24d2bdb7f088e3c8f203bb52cbe20c9789534651b6327455d42f3b2b1c4`
- 7構成ファイル：`k09栃木県/k9栃木県.dbf`、`.prj`、`.sbn`、`.sbx`、`.shp`、`.shp.xml`、`.shx`。日本語ファイル名はCP932由来。展開後計21,266,034 bytes。各ハッシュは研究台帳JSONに記録。
- 元GIS：ShapefileのPOLYGON型5、JGD2000（GCS_JGD_2000）。SHP 1,798件、SHX 1,798件、DBF 1,798件。pyshpですべての形状・属性を読み取り。
- bbox（経度・緯度）：`[139.36266168493395,36.202170868189896,140.27868234459973,37.1355197419129]`
- 県名フィールドKEN_1：1,798件すべて「栃木県」。SICHOはすべて空欄。
- XMLメタデータ作成日：2017年1月17日。2026年の農地現況・現在の自治体境界を保証しない。
- NARO農研機構「日本土壌インベントリー／農耕地包括土壌図」は元データの候補： https://soil-inventory.rad.naro.go.jp/download5.html 。**公式配布ZIPとのSHA-256一致は未確認**。そのため本原本へのライセンス適用の検証状況はNOT_VERIFIEDのまま。

## 重要：行政コードと市町村名の大規模な不整合

- 市町村名フィールドは**26種類**（旧名称「岩舟町」を含む51件）。**JCODEは32種類**。両者の組合せは**85通り**。行政コードと市名は1対1に対応しない。
- 元ファイルには栃木県「09」でなく茨城県「08」で始まるJCODEが**6種類・7組合せ・計19ポリゴン**含まれる。例：`08207 / 小山市`（8件）、`08227 / 真岡市`（3件）。
- 栃木県内の`09201`も宇都宮市だけでなく周辺複数自治体名に関連付いている。**県コード「09」の行も市町村名との対応を信頼できない**。
- 原本の行政コード・市名は勝手に修正しない。研究台帳に85組合せと複数対応・08接頭コードの詳細を固定し、GX Data Atlasには要照合の注意書きを掲載する。
- 既存の稲作統計やJAXA土地被覆とJCODEのみでJOINするのは不適切。正規化には、公式自治体コード台帳、当該GISの位置と自治体境界、原本作成・加工履歴を照合し、監査可能な別版として修正する必要がある。
- 複数自治体名が収録された理由は現時点では未確認。誤った属性が付与された可能性はあるが、**根拠なく原因は断定しない**。

## NaFT P37の公開ファイル

- `research/p37-tochigi-soil-shapefile-source-v1.json`：元ZIPと7ファイルのSHA、GIS範囲、地目4種類、JCODE×市町村名の85組合せと異常値、科学的な利用境界。
- `scripts/p37-tochigi-soil-audit.py`：原ZIPを保持する環境では全7メンバのSHA-256とSHP/SHX/DBF全1,798件・85組合せを再照合する `verify`。GitHub CIでは原ZIPを保持せず登録台帳のみの`audit`。
- `src/gx-tochigi-soil.js`：GX Data Atlasの栃木県選択時だけ集計カードと85行の要照合テーブルを表示。別の都道府県では表示しない。
- `tests/p37-tochigi-soil-gis.test.mjs`：原ZIPハッシュ台帳、地目・コード名前の不一致、旧自治体名・08プレフィックス維持、画面・既存8都道県回帰の検査。

原ZIPをローカルで照合するコマンド：

    python3 scripts/p37-tochigi-soil-audit.py verify '/private/local/栃木県.zip'

公開CI：

    python3 scripts/p37-tochigi-soil-audit.py audit
    node tests/p37-tochigi-soil-gis.test.mjs

公開CIのaudit成功だけで原ZIPのバイト検査が実行されたと表現しない。ユーザーから提供された元ZIPの全7メンバは受入時のローカル環境で検査した。
