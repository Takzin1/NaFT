## 本番NaFTへの統合

P21（３枚）＋P22（１枚）＋P23（６枚）＋P24（６枚）＋P25（６枚）＝**22枚**の累積タイルをGX Data Atlasで選択可能。過去の台帳は変更せず、既存16タイルのID、分類数を保持したまま６枚の分類集計を追加する。**第２バッチのうち過去未反映の５枚は22枚に含めない。**

原本GeoTIFFはGitHubにコミット・再配布しない。NaFTに保持するのは元ファイルSHAと不可逆な分類別集計。発行元の原本との独立バイト照合と再配布許諾は未確認。ユーザー提供原本とのSHA一致は公的な地理分類の正しさや権利を証明しない。

## 原本の再検証（ローカル）

```bash
python3 -m pip install rasterio numpy
python3 scripts/p25-jaxa-lulc-batch05-verifier.py /path/to/original-tifs
node tests/p25-jaxa-lulc-batch05.test.mjs
python3 tests/p25-jaxa-lulc-batch05.test.py
```

Pythonベリファイアは６枚のハッシュ・ファイルサイズを確認してからラスタをブロック単位で全件走査し、地理境界、解像度、15分類の件数が固定台帳と完全一致するか検査する。CIは元の生ラスタを保持していないため、登録済み出典台帳・履歴・画面状態、改変拒否などの回帰テストのみを実行。**このバッチの原本６枚についてはローカルで実際に全画素検査済み**。

## 統計上・制度上の限界

水域（1）は正しい土地分類であってNoDataではない。EPSG:4326の角度画素を均一な10m×10m面積と見なさず、haへ自動換算しない。2024年の土地分類を2001〜2015年のCH₄推計と同一年として扱わない。正式なAG-005適格性、農家の作業履歴、現地精度、クレジットの認証は本第５バッチでは評価しないため、正式面積・認証済みtCO₂eはJSONでnullのまま。
