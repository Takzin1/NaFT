# NaFT P49｜岐阜県農耕地土壌GISの原本検証・行政コード／郡名／土壌分類欠損

ユーザー提供の `岐阜県.zip` を2026-11-10にローカルで開き、全構成ファイルSHA-256、SHP/SHX/DBFの1,942件、土地利用と原本属性を確認した。外部に再配布許諾が確認できていないので、GitHubは**原本のShapefile／DBF／ZIPを含まない**。派生カウントと検証方法のみを掲載する。

## 元ZIP・幾何

- 原ZIP：**7,457,793 bytes**、SHA-256 `aacfafa39e6864d1407d25e0190e33b8163d451e56dfaabf7b347797e5926edd`。
- ZIP内フォルダ：`k22岐阜県`、関連ファイル7個（`.dbf`, `.prj`, `.sbn`, `.sbx`, `.shp`, `.shp.xml`, `.shx`）、CP932日本語ZIP名。展開後バイト合計**12,889,890**。各メンバーのSHAは `research/p49-gifu-soil-shapefile-source-v1.json` に固定。
- ESRI Shapefile POLYGON（shapeType=5）、GCS_JGD_2000。SHP・SHX・DBFは全て**1,942ポリゴン／レコード**で一致。原本全形状とDBFを検査。
- 原本bbox（経度、緯度）`[136.34056869396517,35.14562257312633,137.59267149914808,36.460691180288364]`。
- `KEN_1=岐阜県`、`SICHO`空欄は全レコード。原本XMLのメタデータ作成日は2017-01-17。2026年現況や測量日時とは限らない。

## JCODE／自治体名称：47都道府県コードとの混合に注意

- 市町村名42種類、JCODE45種類、**JCODE×市町村名101組合せ**。
- 岐阜県の `21` で始まらないJCODEが**3件**：富山県 `16` 系2（`16201／飛騨市`1、`16210／白川村`1）、長野県 `20` 系1（`20423／中津川市`1）。
- JCODE**21種類**が複数名称に、名称**33種類**が複数JCODEに対応。地理的な市町村帰属を、この原本JCODEだけで確定しない。CSV/台帳では元の組合せ・地目件数を保持し、正規化や現行行政コードへの置換は行わない。

## GUN（郡名）不整合と空欄

- **GUN×市町村名62組合せ**、郡名が空欄のポリゴン**1,363件**、郡名付き**579件**。
- 原本には `JCODE=20423／中津川市／GUN=木曽郡／田` 1件がある。**木曽郡は長野県の郡名**なので、要照合のまま保存する。
- 郡名の空欄レコードで、同一市町村名に郡名付きレコードも存在するものが**16組合せ・234件**。
- 郡名が複数記録された町は**大野町（安八郡／揖斐郡）、池田町（安八郡／揖斐郡）、垂井町（不破郡／養老郡）、輪之内町（安八郡／養老郡）**の4名称。GIS位置や郡界との照合が済むまで元レコードを上書きしない。

## 土壌分類の空欄

- `JCODE=21211／美濃加茂市／田` 1件で、`群コード`、`包括_統群`、`亜群コード`、`統群コード`がすべて空欄。
- 原本空欄のまま研究台帳に記録。**無断で周辺の土壌型を埋めず、欠損群として扱う**。ゆえに冒頭のdistinct値は欠損を含む数である。

## 再検証方法

公開CI（元ZIPを保存しない・台帳の集計と整合を検査）：

    python3 scripts/p49-gifu-soil-audit.py audit
    node tests/p49-gifu-soil-gis.test.mjs

ユーザー提供原ZIPを持つ非公開ローカル環境（ZIPハッシュ、7構成ファイルSHA、SHP/SHX・DBFの全件再検証）：

    python3 scripts/p49-gifu-soil-audit.py verify '/private/local/岐阜県.zip'

**CIのaudit成功は原ZIPをCIでハッシュ再照合したことを意味しない。** ZIP全体のSHA、構成ファイルSHA、全形状・DBFの独立検証は受入時にローカルで実施した。

追加ファイル：`research/p49-gifu-soil-shapefile-source-v1.json`（検証台帳）、`scripts/p49-gifu-soil-audit.py`（std-libオフライン監査）、`src/gx-gifu-soil.js`（岐阜県パネル）、`tests/p49-gifu-soil-gis.test.mjs`（監査・回帰検査）。`naft-app.html`・`src/gx-data-explorer.js`・`tests/run.sh`に接続。
