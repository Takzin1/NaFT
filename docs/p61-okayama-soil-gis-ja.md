# NaFT P61｜岡山県農耕地土壌GIS：原本来歴・行政属性監査・安全な再利用

## 原本とデータ保全

2026-11-10提供の `岡山県.zip`：13,379,023 bytes、SHA-256 `beb5ffe3f03d788641d952b9d51621ee1d70612d7bd544b82b03476d94b3b47d`。内部には `k33岡山県` のDBF/PRJ/SBN/SBX/SHP/SHP.XML/SHX計7ファイル、展開計20,735,752 bytes。SHP・SHX・DBFはいずれも**1,151レコード**で一致、SHX全レコードのオフセットとSHPのレコード位置も照合済み。ESRI POLYGON (shapeType=5)、GCS_JGD_2000。XMLメタデータ作成日2017-01-17であり、2026年の現地観測を示すものではない。

出典候補は農研機構「日本土壌インベントリー」https://soil-inventory.rad.naro.go.jp/download5.html 。公式ZIPとのバイトSHA照合・発行者認証・再配布許諾は**未確認**。したがって、元ZIP、SHP/DBFや個別地物座標は公開GitHubへコミットしない。公開するのはハッシュ、派生集計、再現手順と監査コードのみ。

## 原本行政属性の要照合事項

- `KEN_1` は1,151件すべて岡山県、`SICHO` は全件空欄。原本の市町村・行政区名30種類、JCODE33種類、JCODE×名称80組、GUN×名称43組。
- **県外系JCODE4件**：兵庫県系28の `28501` は美作市の田1件・普通畑1件、鳥取県系31の `31364` と `31403` は真庭市の普通畑各1件。元値を誤りと断定せず、自治体コードでの自動JOINを禁止。
- 18種類のJCODEが複数名称、22種類の名称が複数JCODEに対応。歴史的境界や元データの作成条件の差は未解決。
- **GUN空欄891件**、そのうち同名の郡名付き原本が存在するものは222件。県外由来の郡名：佐用郡2件・東伯郡1件・日野郡1件。真庭市で東伯郡と日野郡の二種類が混在する。
- 土壌群18種類、詳細土壌分類85種類で、原本の必須土壌分類属性の欠損は0件。

## 公開監査とローカル全件検証

- `research/p61-okayama-soil-shapefile-source-v1.json`：原本全7ファイルのSHA-256、80/43組の原本派生集計、コードと郡名の要照合記録。
- 公開CI：`python3 scripts/p61-okayama-soil-audit.py audit` および `node tests/p61-okayama-soil-gis.test.mjs`。
- 原本ZIPを持つ許諾済みローカル環境：`python3 scripts/p61-okayama-soil-audit.py verify /private/岡山県.zip`。ZIP全バイトSHA、7構成ファイルのハッシュ、SHP/SHX全1,151レコードの位置、DBF1,151行のCP932属性と集計を再検証。
- GX Data Atlasで `prefCode=33` を選ぶと地目別件数、JCODE×名称80組、GUN×名称43組、行政属性の要照合を表示。

**科学的な制限**：ポリゴン件数は農地面積ha、土壌炭素量、GHG排出・削減量、CO₂e量、認証済みJ-クレジットではない。現行行政区や圃場単位に使うには境界・年代・方法論・一次証拠・人による確認が別途必要。
