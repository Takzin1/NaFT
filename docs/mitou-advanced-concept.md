# 未踏アドバンスト向け構想書：NaFT — 市民参加型GXプロトコル

> 本書は未踏アドバンスト事業への提案骨子であり、現時点のNaFTは**法務レビュー前のPoC/研究開発プロトタイプ**です。実決済・実カーボンクレジット売買・換金性のある価値の発行は行いません。
>
> NaFTポイントおよびデモステーブルトークンは、法定通貨・暗号資産・電子決済手段ではありません。本サービスの初期版は、地域GX活動と環境価値の可視化を目的としたPoC・実証実験用のシステムです。実際のカーボンクレジット売買・償却・金融決済は、専門家・提携機関との確認を経て段階的に実装予定です。

## 1. プロジェクト名

**NaFT（Natural-Fungible Token / 自然代替性トークン）— 市民参加型・地域GX公共プロトコルの研究開発**

## 2. 解決したい課題

カーボンクレジット制度は専門家・大企業中心に設計されており、(1) 農家・小規模事業者には算定・証憑・申請のハードルが高く、(2) 市民には参加する接点がなく、(3) 地域で生まれた環境価値が地域経済の中で循環する経路が存在しない。結果として、地域GXは「見えない・自分ごとにならない・広がらない」まま分断されている。

## 3. 提案：GXの「登録→審査→支援→台帳→還元」を一つの公共プロトコルに

NaFTは、地域GX活動のライフサイクル全体を単一のプロトコルとして定義・実装する。

```
事業者がCO2削減活動を登録（算定根拠＋証憑）
 → 地域管理者（自治体/地域金融/運営団体）が審査 …… Human-in-the-loop
 → 市民が非換金ポイントで支援（全国から）
 → すべて取引台帳＋監査ログに記録
 → 炭素配当（GX還元チケット）として地域に還元
 → 地域/全国ダッシュボードで成果を可視化
```

## 4. 新規性・独創性

1. **プロトコルとしての統合** — 既存事例は「可視化アプリ」「地域ポイント」「クレジット取引所」のいずれか単機能。NaFTは審査ワークフロー・台帳・監査・還元・ダッシュボードを不可分の一体として設計し、地域単位で複製可能なホワイトラベル型プロトコルにした点が新しい。
2. **Compliance-by-design** — 非換金・限定用途・意思表示（購入予約）という設計制約をプロトコル自体に埋め込み、資金決済法・金商法等への抵触を構造的に回避しながら価値循環を実験できる。法務レビューと並走可能な「段階的合法化アーキテクチャ」。
3. **Human-in-the-loop審査** — AIは証憑要約・算定論点の提示・異常検知の補助に徹し、承認判断と説明責任は常に人間の管理者に置く。公共性の高い価値配分におけるAI利用の設計規範を実装として示す。
4. **Web3を「将来の接続先」として予約** — 全取引にオンチェーン連携カラムを確保しつつ、現段階では接続しない。技術的可能性と法的段階性を分離した設計。

## 5. 現在の実装状況（応募時点）

- 単一HTML SPAとして**全機能が動作するPoC**（8ロール・30画面超・支援/審査/還元/台帳/監査/CSV）
- スモークテスト46項目自動化、Solidityコントラクト雛形3種（未接続）
- ドキュメント一式（アーキテクチャ/データモデル/法務リスクマップ/HITL設計）

## 6. 未踏期間の開発計画（概要 → docs/roadmap.md）

サーバー実装への移行（権限のサーバー側強制）、証憑のハッシュ保全とMRV連携設計、AI審査補助（HITL）の実装と評価、1地域でのクローズド実証（市民50–100名）、法務専門家レビューを経た制度接続設計。

## 8. 想定質疑（抜粋）

- **Q. ポイントに換金性がない中で市民は参加するのか** — A. ふるさと納税・クラウドファンディングが示す「地域を応援する動機」に、CO2貢献の定量可視化と地域で使える炭素配当を重ねる。実証で参加動機・継続率を測定すること自体が本研究の評価項目である。
- **Q. 既存のJ-クレジットと競合しないか** — A. 競合ではなく手前工程。制度化以前の「候補」段階の活動を可視化・審査・支援し、成熟した案件を制度へ接続する導管を目指す。
- **Q. なぜブロックチェーンを今使わないのか** — A. 法的段階性のため。台帳スキーマに連携カラムを確保し、法務レビュー後にテストネット→本接続へ段階導入する。
