# NaFT P56｜兵庫県農耕地土壌GIS 原本監査・GX Data Atlas

2026年11月10日受領のユーザー提供原本 `兵庫県.zip` をローカル検査。公開GitHubへは**元GISファイルを入れず**、ハッシュ・原本属性の派生集計・検査コード・表示ロジックのみを登録する。

## 原本保全と来歴

- ZIP `兵庫県.zip` **11,256,943 bytes**、SHA-256 `d0e2c012e060014b341595d3a34aadb83498476290c7a1ae1cd2a27363733e38`。
- ZIP格納先 `k28兵庫県/`、DBF/PRJ/SBN/SBX/SHP/SHP.XML/SHXの**7構成ファイル**、非圧縮計**17,355,914 bytes**。個別ハッシュは `research/p56-hyogo-soil-shapefile-source-v1.json`。
- ESRI POLYGON shapeType 5、GCS_JGD_2000、範囲 `[134.27031944612435,34.16185850089661,135.4491554823112,35.668150185835]`。SHP、SHX、DBFの行数はともに**1,216件**。`KEN_1=兵庫県`、`SICHO`全件空欄。
- 元XMLの**メタデータ作成日は2017-01-17**。これは観測年や現況の保証ではない。
- 農研機構「日本土壌インベントリー」 https://soil-inventory.rad.naro.go.jp/download5.html は出典候補だが、**公式配布ZIPとのSHA完全一致、データセットへの個別ライセンス適用、再配布条件は未確認**。

## JCODE・市区町村の整合性

- JCODE **46種類**、`SIKUCHOSON` **44種類**、原本JCODE×市区町村名**102組合せ**。
- 県外のJCODE **8ポリゴン**（京都府「26」系6件・大阪府「27」系2件）、合計**5組合せ**。原本のまま保持する。
- 25種類のJCODEが複数名称に、31種類の名称が複数JCODEに対応する。よって自治体統計への単純なJCODE JOINは禁止。
- **旧市名「篠山市」32ポリゴン**。2019年に「丹波篠山市」へ改称されたため、2017年作成メタデータの原本名称という事実のみで誤入力とは判断しない。元属性は改名・正規化しない。

## 原本GUN（郡名）と年代差

- `GUN` 空欄942件、記載274件。原本GUN×名称**52組合せ**。
- **「船井郡／篠山市」1件（田・JCODE 26407）**。船井郡は京都府に属する郡名で、府県境の行政コードと地理的対応に疑義がある。原本を補正せず要照合とする。
- 同じ原本名称でGUN付きのレコードも存在するGUN空欄**71ポリゴン**。このうち町名**40件**、旧市名「篠山市」**31件**。市名のGUN空欄31件を機械的に「欠損」として扱わない。
- `source_gun_quality` の監査レコードが判断の根拠。正式な郡別集計や現代行政コードJOINは行っていない。

## 再現方法

研究台帳：`research/p56-hyogo-soil-shapefile-source-v1.json` にはZIP/構成ファイルのSHA、地目別件数、原本JCODE×名称・GUN×名称の全組合せと要照合フラグを格納する。

標準ライブラリのみで公開台帳をCI検証：

```bash
python3 scripts/p56-hyogo-soil-audit.py audit
node tests/p56-hyogo-soil-gis.test.mjs
```

受領元の非公開ZIPで**ハッシュと全1,216 DBFレコードを再計算**：

```bash
python3 scripts/p56-hyogo-soil-audit.py verify '/private/兵庫県.zip'
```

公開CIの `audit` はコミット済み派生台帳の内部整合性を検査するモード。**元ZIPの完全再照合は `verify` に元ZIPを与えた場合のみ実行**。

`src/gx-hyogo-soil.js` はGX Data Atlasの兵庫県 (`prefCode='28'`) に地目カード、JCODE×名称102組合せ、郡名×名称52組合せ、県外コード・旧名称・郡名の警告を追加する。`tests/p56-hyogo-soil-gis.test.mjs` はデータ改変検知、元27都道府県の表示配線、元データの公開漏洩防止、科学的制約を検証する。

再配布条件が確定していないため原本Shapefile、DBF、ZIPを公開GitHubにコミットしない。2024年水稲統計・JAXA土地被覆との自動JOIN、農地面積やクレジット数量の推計は未検証につき実施しない。
