# NaFT P38｜埼玉県の農耕地土壌GIS原本受入と行政コード不整合の保留

2026-11-09、ユーザー提供の `埼玉県.zip` を検査した。北海道・東北6県・茨城・栃木に続く関東第3弾の研究用GISデータとして、元ZIPと7構成ファイルのSHA-256、図形・属性1,912件を記録。**行政コードと市区町村名が1対1に対応しないため、市区町村別の確定統計には使用しない。**

## 原本の仕様と来歴

- 元ZIP 8,008,925 bytes、SHA-256 `6472a9e2fc0aa25c23e08b3593d9c8bc1135db7e22dd09c8083eb865923ed474`。
- 元の7構成ファイル：`k11埼玉県/k11埼玉県.dbf`、`.prj`、`.sbn`、`.sbx`、`.shp`、`.shp.xml`、`.shx`。元ZIPはCP932日本語名。展開後13,692,638 bytes。各ファイルSHA-256は研究台帳に収録。
- 元GIS：ESRI POLYGON（shapeType=5）、JGD2000（GCS_JGD_2000）。SHP・SHX・DBFはいずれも1,912件。pyshpで全図形と属性レコードを読み込み済み。
- bbox：`[138.8680488573203,35.763381944347785,139.8954271704511,36.27829900000003]`。
- KEN_1の1,912件はすべて「埼玉県」。SICHOはすべて空欄。土壌「群コード」15種類、「包括_統群」64種類。
- 原本XMLのメタデータ作成日は2017-01-17。現在の耕作状況・境界・地目の実態は意味しない。
- 配布元の候補は農研機構（NARO）「日本土壌インベントリー／農耕地包括土壌図」https://soil-inventory.rad.naro.go.jp/download5.html 。**公開されている埼玉県の公式ZIPと今回アップロードされたZIPとのSHA一致はまだ確認できていない。** 本レポジトリでは再配布権限をNOT_VERIFIEDのまま保持する。

## 行政コード（JCODE）と市区町村名称の不整合

- 原本のJCODEは**81種類**、市区町村名は**73種類**、組合せは**215通り**。さいたま市の各区など、区レベルの行政名も含まれるので「73市町村」とは表現しない。
- 県名KEN_1は埼玉県だが、JCODEが県コード「11」で始まらないレコードが**合計17ポリゴン／10コード・名称組合せ**ある。接頭コード別には茨城県「08」が2件、栃木県「09」が3件、群馬県「10」が12件。
- 54種類のJCODEが複数自治体・区名に、64種類の名称が複数JCODEに対応している。例えば`11101`は「西区」のほか「上尾市」「大宮区」「川越市」「桜区」にも使われている。
- 原本には旧称「白岡町」56件・「鳩ヶ谷市」5件が含まれている。
- これらは原本の属性の問題として、値を勝手に書き換えず、研究台帳に215組合せを**原本そのまま**保存し、GX Data Atlasの埼玉県では「要照合」の警告を表示。行政コードに基づく現行市区町村との自動JOINは行わない。誤ったコード付与の原因については、位置・境界・原本加工履歴の検証前に断定しない。
- 旧自治体の歴史的名称、複数自治体名を含むJCODE、県外JCODEの問題は混ぜずに別々に記録する。

## GitHubでの実装内容

- `research/p38-saitama-soil-shapefile-source-v1.json`：元ZIP・7構成ファイルのSHAとサイズ、1,912件の地目4分類、215組合せ、県外コードと旧自治体名の詳細な検証台帳。
- `scripts/p38-saitama-soil-audit.py`：元ZIPのバイト・全7ファイルSHA・SHP/SHX・DBF全1,912レコード・215組合せを独立に照合する `verify`。原本をGitHubに置かず、公開CIでは台帳 `audit` のみ。
- `src/gx-saitama-soil.js`：GX Data Atlasで埼玉県を選択すると、4地目カード・行政コード不整合警告・215組合せの表を表示。
- `tests/p38-saitama-soil-gis.test.mjs`：ハッシュ、集計、県外コード、歴史名、変造検知と、既存9都道県の表示維持をテスト。

手元の元ZIPに対するフルバイト検証：

    python3 scripts/p38-saitama-soil-audit.py verify '/private/local/埼玉県.zip'

公開CIで実施する原本を含まない監査：

    python3 scripts/p38-saitama-soil-audit.py audit
    node tests/p38-saitama-soil-gis.test.mjs

公開CIの `audit` 成功はZIP原本バイト照合成功の代わりにはならない。元ZIPのSHAと全7ファイルは受入時のローカル作業環境で照合済み。

## 科学的・権利上の境界

配布元・再配布ライセンスが今回の原本へ適用されることを完全に確認できるまで、Shapefile/DBF/元ZIPは公開GitHubへ複製しない。公開するのはSHAと派生集計、検証で見つかった不整合情報のみ。農耕地ポリゴン数から農地面積、土壌炭素量、CH₄、CO₂e削減量、J-クレジット量を算出しない（`official_credit_tco2e = null`）。
