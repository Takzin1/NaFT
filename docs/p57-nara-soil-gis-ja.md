# NaFT P57｜奈良県・農耕地土壌GIS原本属性監査

## 1. 原本ZIPの来歴・保全

ユーザー提供の`奈良県.zip`を2026年11月10日に受け入れ、ZIPの7構成ファイル（DBF・PRJ・SBN・SBX・SHP・SHP.XML・SHX）のSHA-256を個別検証した。

- 元ZIP **3,703,958 bytes**、SHA-256 **`6a1787c976149b29fead495730d749b0ce072e1e5d9922f4d25786aba3d61d16`**。
- ZIPフォルダ名 `k29奈良県`（元ファイル名はCP932）、非圧縮7ファイル合計 **6,289,996 bytes**。
- ESRI POLYGON（shapeType=5）、JGD2000（`GCS_JGD_2000`）、範囲 `[135.56310091626395,33.87643163780173,136.21964315993296,34.777998616262266]`。
- SHP、SHX、DBFは**全855件一致**。原本XMLのメタデータ作成日は2017年1月17日。
- `KEN_1`は全件「奈良県」・`SICHO`は全件空欄。
- 出典の**候補**は農研機構「日本土壌インベントリー」 https://soil-inventory.rad.naro.go.jp/download5.html 。**公式ZIPと受領原本とのSHA一致、公式配布元の認証、再配布ライセンスは未検証**であり、候補を公式の確定ソースと表示しない。
- 原Shapefile・DBF・元ZIPは公開GitHubに置かない。検証台帳・派生件数・再現用コードのみ公開する。

## 3. JCODE×市町村名の要照合事項

JCODE**51種類**、原本市町村名**39種類**、両者の組合せ**109**。1コードが複数名称に対応するもの24種類、1名称が複数JCODEに対応するもの28種類。

奈良県「29」以外のJCODEは**33ポリゴン**：
- 京都府「26」系 **16件**
- 三重県「24」系 **9件**
- 大阪府「27」系 **8件**

コードと名称は原本のまま記録し、現行の自治体単位でJOIN・統合・自動補正を行わない。県境跨ぎのジオメトリ・自治体境界・データの年代差を確認するまで原因を断定しない。

## 4. 原本GUN（郡名）の調査

原本のGUN×市町村名は**58組合せ**。GUN空欄**464件**、記載**391件**。

- **「相楽郡」12件**が原本に存在：奈良市11（田6・樹園地5）、生駒市1（田1）。相楽郡は京都府の郡名であり、奈良県名と整合しないため要照合として保持。
- **「河合町」**には北葛城郡・生駒郡・磯城郡の3種類のGUN、**「広陵町」**には北葛城郡・磯城郡の2種類が記録されている。
- 同一名称にGUN記載レコードも存在するGUN空欄は**155件**。うち**町村名79件、市名76件**に区分し、奈良市54件・生駒市22件は府県外「相楽郡」の記録によって抽出されたもの。市名の空欄を、自治体の正式郡名の欠損と決めつけない。

GUN・市町村名・JCODEの原本値は変えず、自治体別・郡別外部統計への自動JOINを保留。

## 5. 検証・表示機能

| ファイル | 役割 |
|---|---|
| `research/p57-nara-soil-shapefile-source-v1.json` | 元ZIPと7メンバーのSHA、全原本派生109 JCODEペア・58 GUNペア、科学的制約 |
| `scripts/p57-nara-soil-audit.py` | Python標準ライブラリで登録台帳の検証、および元ZIPのSHAとDBF855件を再計算 |
| `src/gx-nara-soil.js` | `naft-app.html#/gx-data`の奈良県（prefCode=29）に地目、行政コードと郡名の要照合箇所を表示 |
| `tests/p57-nara-soil-gis.test.mjs` | データ改変・行政異常値・表示の回帰、従来28都道府県の機能維持を検査 |
| `docs/p57-nara-soil-gis-ja.md` | この来歴・研究境界・再現方法 |

公開CIの台帳検査：

```bash
python3 scripts/p57-nara-soil-audit.py audit
node tests/p57-nara-soil-gis.test.mjs
```

原本ZIPを保有する環境の**独立バイト検証**：

```bash
python3 scripts/p57-nara-soil-audit.py verify '/private/奈良県.zip'
```

`audit`はGitHubに登録した研究台帳の**内部整合性検査**であり、`verify`による原本ZIPの独立バイト検証と混同しない。

## 6. dMRVへの科学的な適用境界

ポリゴン数は農地面積ha・筆数・土壌炭素実測値・CH₄実測・CO₂e削減量・認証クレジットではない。2024年水稲統計やJAXA土地被覆等とJCODEを**無検証でJOINしない**。行政境界・基準年・空間位置の整合と人手承認を経た後にのみ統計的利用に進める。
