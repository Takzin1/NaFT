# NaFT P36｜茨城県農耕地土壌GISの受入検証・行政コードと市名の不整合

2026-11-09にユーザー提供「茨城県.zip」を実際に解凍し、原本のSHP・SHX・DBF全1,335件と7構成ファイルのSHA-256を検査した。北海道・東北7道県に続く関東第1弾の研究用GISデータとして登録。

## 原本

- ZIP 16,098,958 bytes、SHA-256 af1bbf9d3c12eb51137e9ec8686f1255010eafa2e5424466a8d39b262d11a44f。
- ZIP内の7ファイル：k08茨城県/k8茨城県.dbf、.prj、.sbn、.sbx、.shp、.shp.xml、.shx。元のファイル名はCP932。展開後総計24,405,160 bytes。各ファイルのSHAは研究台帳に記録した。
- ESRI POLYGON、JGD2000（GCS_JGD_2000）。形状・SHX・DBFすべて1,335件で一致し、全形状を走査できた。
- Bbox：[139.69294608540187, 35.74898638062405, 140.8214158357868, 36.933077667152084]。
- KEN_1は茨城県、SICHOは空欄。群コード13種類、包括_統群51種類。
- XMLメタデータ作成日は2017-01-17。データ作成当時の属性であり、2026年の農地現況ではない。
- 推定される公開元：農研機構（NARO）「日本土壌インベントリー」https://soil-inventory.rad.naro.go.jp/download5.html 。**公式配布ZIPとのハッシュ一致は未確認**。適用ライセンスも、今回ユーザーが提供した具体的な原本との対応確認が終わるまではNOT_VERIFIEDと記録する。

## 重要：JCODE／市町村名の不整合

- 原本に市町村名44種類、行政コード（JCODE）44種類。組み合わせ45通り。
- JCODE「08211」には「常総市」24件（田11、普通畑9、牧草地1、樹園地3）と「守谷市」1件（田1）が混在する。
- 「守谷市」は別コード「08224」でも15件（田8、普通畑5、牧草地2）記録されている。
- これらは**コードと名称の組み合わせの不整合**であり、勝手に現行コードへの上書きや、その1件の別市町村への移動をしない。研究台帳は原本の45組合せを保持、画面上で1件に「要照合」と表示する。
- 現行市町村コードや別年次の農業統計と結合する前に、権威ある行政コード資料・GIS位置・元の修正履歴で照合し、確認結果を別バージョンに記録する。

## GitHubでの成果

- research/p36-ibaraki-soil-shapefile-source-v1.json：元ZIPと全7ファイルのSHA・サイズ、原本の45組合せ、2つの不整合注意事項。
- scripts/p36-ibaraki-soil-audit.py：完全な元ZIPが手元にある環境で全7ファイルSHA・SHP/SHX・DBF全行を再照合する verify と、台帳だけを検証する audit を区別。
- src/gx-ibaraki-soil.js：GX Data Atlasの茨城県でカード・不整合警告・45行の原本集計を表示。
- tests/p36-ibaraki-soil-gis.test.mjs：出典と集計値・コード不整合・県コード選択と既存7道県の機能保持を確認。

元ZIPが手元にあるときの完全なオフライン再検証：

    python3 scripts/p36-ibaraki-soil-audit.py verify '/local/private/茨城県.zip'

公開CIでは元ZIPを保存しないため、台帳のみを検証：

    python3 scripts/p36-ibaraki-soil-audit.py audit
    node tests/p36-ibaraki-soil-gis.test.mjs

CIのaudit成功を元ZIPの独立バイト照合成功と混同しない。

## 公開・科学的境界

元GISの公開元・再配布条件について具体的な原本との完全対応を確認するまで、生のShapefile/DBF/ZIPは公開GitHubにコミットしない。SHAと派生集計のみ掲載。自動的に水田面積、CH₄排出量、土壌炭素量、CO₂e削減量、J-クレジットの認証量へ換算しない（official_credit_tco2e=null）。
