# NaFT P53｜滋賀県農耕地土壌GIS原本監査

2026-11-10、ユーザー提供 `滋賀県.zip` の7構成ファイルを展開し、SHP・SHX・DBF **785ポリゴン**と元の属性を全件監査した。研究用途の派生件数のみNaFT GX Data Atlasに実装する。

## 出典候補と元データの保全

- アップロード元ZIP：4,887,387 bytes、SHA-256 `3fef4ebc36d2856543a0034f05815fb1961e37b9ad1a160883d2ad22a0229a19`。
- ZIP内部：`k25滋賀県`、構成はDBF・PRJ・SBN・SBX・SHP・SHP.XML・SHXの7ファイル、解凍総容量7,899,584 bytes。構成ファイル個別のSHA-256・サイズは `research/p53-shiga-soil-shapefile-source-v1.json` に固定。
- 図形型：ESRI POLYGON（5）。元座標系：GCS_JGD_2000。原本のbbox：`[135.7872572992245,34.79754192350782,136.43336700581398,35.671852353859066]`。
- DBFレコード・SHP/SHX図形インデックスはそれぞれ785件で一致。原本 `KEN_1=滋賀県`、`SICHO`は全件空欄。XML作成日：2017-01-17（2026年の現地観測を意味しない）。
- 出典の**候補**は農研機構（NARO）「日本土壌インベントリー」 https://soil-inventory.rad.naro.go.jp/download5.html 。公式滋賀県ZIPとの原本SHA-256照合と再配布許可は**未確認**。生のZIP、SHP、DBFなどの権利未確認データは公開GitHubにコピーしない。

## JCODE・市町村名の疑義（原本のまま保存）

- JCODE22種類・市町村名19種類、JCODE×名称51組合せ。
- 原本 `KEN_1=滋賀県` に対して、県外JCODEは**5ポリゴン・3組合せ**。岐阜県「21」系 `21362／米原市` 1件（樹園地）、三重県「24」系 `24210／甲賀市` 1件（樹園地）と `24216／甲賀市` 3件（田）。
- **14 JCODEが複数市町村名**に、**15市町村名が複数JCODE**に対応。原本JCODEを現行行政コードと見なした外部統計への自動JOINは禁止する。

## 原本GUN・郡名の疑義

- GUN空欄は**662件**、記載ありは**123件**。内訳：蒲生郡56、犬上郡41、愛知郡25、岐阜県の**不破郡1**。
- `不破郡／米原市` は県外郡名（樹園地1件）。**米原市のGUN空欄56件**は、同名に県外郡名付きレコードが存在するため「要照合」と検出されたもの。市の郡名空欄56件を、欠損と断定しない。
- `豊郷町` のGUNには `犬上郡`（10ポリゴン）、`愛知郡`（3ポリゴン）が共存し、さらに空欄5件もある。ここでの「愛知郡」は滋賀県にある郡名に由来する属性で、愛知**県**の郡名と混同せず、原本の年代・区界を別途調査する。
- 同じ名称でGUN付き記録もあるGUN空欄は計**94ポリゴン**。町名は**38件**、米原市は**56件**。市・町の区別を維持し、自治体ごとの郡名自動補完はしない。

## 再現・検証方法

公開台帳：`research/p53-shiga-soil-shapefile-source-v1.json`

監査コード：`scripts/p53-shiga-soil-audit.py`

UI：`src/gx-shiga-soil.js`（prefCode `25`）。

回帰テスト：`tests/p53-shiga-soil-gis.test.mjs`（従来24都道府県の画面を回帰保護）。

公開CIで動く**派生台帳の内部整合性チェック**：

```sh
python3 scripts/p53-shiga-soil-audit.py audit
node tests/p53-shiga-soil-gis.test.mjs
```

原本ZIPを保有するローカル環境で行う**元ZIP・全7メンバー・DBF785行・SHP/SHXの完全再検証**：

```sh
python3 scripts/p53-shiga-soil-audit.py verify '/local/private/滋賀県.zip'
```

CIには権利未確認の生GISを含めないため、`audit`による台帳の検証は`verify`による元ZIPの完全再検証と**同義ではない**。受入時にはローカルでアップロード原本と図形・属性785件を検査済み。

## 科学的・行政上の境界

ここでの件数は土壌分類・地目分類を持つポリゴンフィーチャの行数。農地面積ha、筆数、実測土壌炭素、CH₄排出量、CO₂e削減量、J-クレジット認証量ではない。地目の件数から面積・炭素量を推計しない。地理的な位置関係や行政コードの時点が未照合のまま、2024年水稲統計やJAXA土地被覆データ等との行政コード自動結合をしない。
