## 1. GMW：GeoTIFF原本44枚の解析

- 名前は \`GMW_N19E108_v4112_mng_ext.tif\` 等。**44枚とも単一の1度×1度タイル、3711×3711ピクセル、EPSG:4326、41バンド、uint8**。
- アーカイブ全体のタイル位置の**包絡範囲**は経度108〜139°E、緯度18〜35°N。これは**実際に存在するタイル集合の範囲を囲う矩形であり、矩形全域にタイルがあるという意味ではない**。
- 読み込んだバンド1の値1の画素は44枚合計**145,798**、バンド41は**339,302**。画素値0はGeoTIFFでNoDataにも設定されており、「0が絶対にマングローブ不在」という論理には変換しない。
- 41バンドは1985〜2025年の41年に対応する可能性があるが、**GeoTIFF内のバンド年月を特定するメタデータは見つからない**。正式なバンド→年の対応を確認するまでは、バンド1を1985年、バンド41を2025年と**断定しない**。
- 画素数の差分を面積haや二酸化炭素吸収量t-CO₂に変換しない。緯度ごとに画素の実面積は変わるほか、データ版や分類・観測品質の影響がある。
- マングローブ植生分布＝炭素**ストック**または年間GHG**フラックス**ではない。Jブルーの認証済クレジットや法的移転権はない。

## 2. アジアCH₄同位体観測の解釈

有効70件（末尾空白25行を除外）、2021〜2025年、**日本54／タイ12／バングラデシュ4件**。

| 発生源 | 行数 |
|---|---:|
| 埋立地（landfill） | 55 |
| 下水（sewage） | 8 |
| 水田（rice paddies） | **4** |
| ガス漏出（gas leak） | 2 |
| 作物焼却等（crop） | 1 |

- 元CSVにある \`d13C_CH4\` はメタンの安定炭素同位体の**発生源指紋**。CSVの列名だけで国際標準の単位・測定基準を断定しない。
- **水田は茨城県2件（−67.7、−58.2）、バングラデシュ2件（−59.8、−62.8）**。少数例にすぎず、各国平均や農業削減量として一般化できない。
- タイの12件は埋立地と下水であり、今回のCSVに**タイの水田実測値はない**。
- \`Unc_d13C_CH4\` は原資料の同位体測定不確実性。CH₄排出フラックスの不確実性・CO₂e換算の許容誤差ではない。
- 地点座標は原本の取込とローカル再現可能な記録に保持するが、Public Repoの派生CSVは**地点座標を除外し、国×区分の9グループの単純平均・最小/最大と件数だけ**を保持。
- \`N_AirSample\` は各記録に紐づくサンプル数（全70行の合計383）。383を「互いに独立する383地点」とみなさない。

[出典と国別／発生源別の分布](../research/sea9-rice-ch4-2026-11-08/asia-ch4-isotope-source-register.json) ／ [9区分の派生集計CSV](../data/sea9-rice-ch4-2026-11-08/asia-isotope-country-category-aggregates.csv)

## 3. SEA-9研究との結合条件

| 入力 | 科学的意味 | 現在許可する処理 |
|---|---|---|
| SEA-9 v1.0.0 | 2020–2021年の9か国の**水田CH₄排出量推計** | 国別GHG推計の比較・MCの再集計 |
| GMW 4.1.12タイル44枚 | 東アジアの一部の**植生分布** | 出典・GeoTIFF構造・バンド別の画素計数 |
| アジア同位体70件 | 日本・タイ・バングラデシュの**CH₄発生源指紋** | 発生源の分類・観測／不確実性管理 |

**この3つは時間・空間・単位・現象が異なる。** 例えば「タイが両データに登場」しても同じ水田の観測とは限らず、タイ同位体12件は水田ではない。衛星植生分布やδ¹³C-CH₄から水田CH₄フラックス、削減率、J-クレジットの発行量を導出しない。

## 4. ローカル原本の完全SHA照合

    python3 scripts/p27-gmw-isotope-intake.py \
      --gmw-zip "/local/GMW-10_v4112.zip" \
      --isotope-csv "/local/Isotope_CH4_source_inventory_Asia_ver.1.0.csv" \
      --out ".naft-local/p27-gmw-isotope" \
      --verify-raster

\`--verify-raster\` は追加でrasterioを要し、44枚全ての**バンド1/41の表示画素数・CRS・サイズ・型**を照合する。\`--extract-tiles\` を付けたときだけ、原本GeoTIFFをローカルに展開する。標準の取込は元のPythonコードやネットワークを実行しない。

出力される \`source-integrity-receipt.json\` には**原本SHA、44タイルの一致、70件のCSV確認、年次・CO₂e・法的権利を検証していないこと**を明記。個別座標を含むCSVの全行は .naft-local ディレクトリにのみ出力。

テスト：

    python3 tests/p27-gmw-isotope-intake.test.py

GitHub Actionsは原本ファイルを含まず**固定出典と架空CSV・拒否系をテストする**。Actions成功が原本のGeoTIFF画素をGitHub上で再検査したという意味ではない。実際のGeoTIFF画素は今回のアップロード原本に対しローカル環境のrasterioで確認済み。
