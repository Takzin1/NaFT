# NaFT P52｜三重県農耕地土壌GIS：原本属性と監査履歴

2026年11月10日、ユーザー提供 `三重県.zip` を解凍し、7構成ファイル、SHP・SHX・DBFの全1,626ポリゴンを検査した。研究用の地目・JCODE×市町村名・GUN郡名×市町村名の派生集計のみ公開する。原本の属性に行政コードの混在、郡名の多重対応、土壌分類の欠損があるため、現行の行政データへの自動JOINや排出量換算を実施しない。

## 1. 原本のバイトハッシュ

- 元ZIP：`三重県.zip` 7,025,476 bytes。SHA-256 `d5664f056820a9957a7dadfca398d927f82e694532ad5965a8ad812337523ce1`。
- 内部フォルダ `k24三重県`。構成：`.dbf` `.prj` `.sbn` `.sbx` `.shp` `.shp.xml` `.shx` の7ファイル、合計11,810,962 bytes。すべての個別SHAは研究台帳に記録。内部の日本語ファイル名はCP932。
- ESRI POLYGON（shapeType=5）、`GCS_JGD_2000`。SHP・SHX・DBFいずれも1,626件で一致し、原本図形を全件走査。bboxは`[135.85774174419456,33.724702511083706,136.92376760129673,35.236689212016046]`（経度・緯度）。
- `KEN_1`は全件三重県、`SICHO`は全件空欄。XMLメタデータの作成日2017-01-17は、2026年時点の現況を保証するものではない。
- 元資料候補：農研機構（NARO）「日本土壌インベントリー」 https://soil-inventory.rad.naro.go.jp/download5.html 。**公式三重県ZIPとのバイト完全一致、ライセンスの個別適用、再配布権利は未検証**。

## 3. JCODEの混在・複数対応

- `SIKUCHOSON`29種類、`JCODE`31種類、**JCODE×名称58組合せ**。14種類のJCODEは複数名称に、19名称は複数JCODEに対応している。
- 三重県「24」系ではないコードは合計**9ポリゴン**：
  - 岐阜県「21」系：`21221／桑名市` 6件（田3・樹園地3）。
  - 愛知県「23」系：`23235／木曽岬町` 3件（田2・普通畑1）。
- 元GISの図形との位置関係や行政界・コード年代の確認が終わるまで、これらを自動修正せず現行市町村統計と無条件に結合しない。

## 4. GUN（郡名）の多重対応と空欄

- 原本のGUN空欄**1,104件**、郡名記載**522件**。郡別：度会郡161、多気郡159、南牟婁郡79、三重郡61、北牟婁郡29、員弁郡21、桑名郡12。
- **GUN×市町村名41組合せ**を地目別に収録。
- 「玉城町」「度会町」「大紀町」には**多気郡と度会郡の両方**の原本属性がある。これらが歴史的な行政境界や原データの付番方法に由来するのかは未検証で、正規化しない。
- 同じ町名について郡名が付いた別レコードが存在するのにGUNが空欄のレコードが**80ポリゴン**（多気町6、川越町2、御浜町6、明和町19、朝日町2、木曽岬町3、東員町14、玉城町10、菰野町18）。
- GUNの空欄を郡名が欠損していると断定せず、「原本GUN空欄・要照合」という独立のフラグで残す。

## 5. 土壌分類の欠損

原本のDBF **413番目**、`JCODE=24210／亀山市／田` の1件は、`包括_統群`、`統群コード`、`亜群コード`、`群コード` の主要4項目が**すべて空欄**。土壌分類の穴埋め・推測は行わず、値の欠損として検証台帳とUIに明示する。

## 6. 再現手順と実装箇所

- `research/p52-mie-soil-shapefile-source-v1.json`：元ZIP・各メンバのサイズとSHA-256、58 JCODE×名称・41 GUN×名称、土地利用内訳、行政属性・土壌分類の例外を収録。
- `scripts/p52-mie-soil-audit.py`：Python標準ライブラリだけで台帳を検査。`verify`では原本7構成ファイルの全SHA-256とSHP/SHXの各ポリゴン・全DBF1,626行・欠損レコードを再計算する。
- `src/gx-mie-soil.js`：GX Data Atlasの三重県（コード`24`）画面に4地目カード、原本JCODE×名称58組合せ、GUN×名称41組合せ、異常値警告を追加。
- `tests/p52-mie-soil-gis.test.mjs`：原本の属性件数と例外、欠損1件、表示、従来の23都道府県の回帰をガード。

公開GitHub Actionsでの監査（元の生GISは置かない）：

    python3 scripts/p52-mie-soil-audit.py audit
    node tests/p52-mie-soil-gis.test.mjs

元ZIPのある手元の環境で原本をバイト再照合：

    python3 scripts/p52-mie-soil-audit.py verify '/private/path/三重県.zip'

**公開CIの`audit`成功は、元ZIPのバイト照合成功と同義ではない**。原本の完全な検査には手元の原本ZIPが必要。

## 7. 研究上・配布上の制約

出典候補のライセンス条件が確定するまでは、**元Shapefile・DBF・ZIPの生データを公開GitHubへ複製しない**。ポリゴン件数を農地面積ha、筆数、土壌炭素実測値、CH₄実測値、CO₂e削減量、認証済みJ-クレジットに換算しない。2024年水稲統計、JAXA土地被覆、現行市町村コードとの自動JOINは未検証のため保留する。
