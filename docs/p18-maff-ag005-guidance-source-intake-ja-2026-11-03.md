## 重要な版分岐（出典ページはPDFの1始まり）
- 概要 **p.13, p.19–21**：水稲栽培の直近2か年以上の中干し日数平均より7日以上、かつ連続。水稲未栽培年は基準から飛ばす。差し水後の連結計算は禁止。
- 概要 **p.14–16, p.23, p.28–29**：生産管理記録と開始・終了の客観的証跡、出穂日、作付面積、所在地域、前作稲わらと堆肥。日減水深を測定しなければ最低係数側となり、高い係数の採用はできない。
- 概要 **p.32** とガイド **p.18–19**：**2025-01-01以降の活動**の個別活動実績報告リストには、旧方法論（Ver1.0–3.1）で登録されたプロジェクトにもeMAFF地番転記要件が及ぶ。
- ガイド **p.4–16**：2024年産以前は１行１地番、別管理筆と面積二重計上に注意。
- ガイド **p.19–29**：2025年産以降、eMAFF農地ナビの所在地番と面積根拠資料の地番は別列。eMAFFに地番が全くない筆は不在画面の証跡と書類の優先順位に従う。地番・筆・面積に衝突がある場合は手動確認。
- ガイド **p.31–32**：認証対象期間は筆ごとに原則8年。名義変更と営農慣行変更に伴う基準年の再設定は専門レビュー。
- 概要 **p.35–39**：水生生物、生育と減収、カドミウムと食品安全、クレジット売却後の環境価値二重主張は禁止。農業者の安全をクレジット取得より優先。

## 実装と限界
`scripts/p18-ag005-source-intake.mjs` の `audit` はレジストリを監査し、`verify-local` は手元に合法的にある原本PDFのバイト一致を確認する。CIには原本を含めず、固定されたメタデータと合成入力によるテストを入れる。

```bash
node scripts/p18-ag005-source-intake.mjs audit
node scripts/p18-ag005-source-intake.mjs verify-local MAFF_AG005_OVERVIEW_2026_07 '/private/index-175.pdf'
node scripts/p18-ag005-source-intake.mjs verify-local MAFF_AG005_ACTIVITY_GUIDE_2025_12 '/private/nakaboshi_guide.pdf'
node tests/p18-ag005-source-intake.test.mjs
```

`precheck <request.json>` は **欠落した証憑と要手動確認項目の研究用チェック**だけを行う。入力のtrueは自己申告であり証拠の真偽や制度適格性を認証しない。結果の `certified_tco2e` と `carbon_credits_issued` は常に `null`。排出係数はロードせず、クレジット発行に関与しない。

**本２資料は説明資料・実務ガイドであり、方法論AG-005の正式採択版の一次認証ではない。** ガイドがVer.3.3を引用していても、法令上の現行適用版・移行措置・使用係数はJ-クレジット事務局の原文および審査機関で別途確認する。2025年産前後の境界、複数地番・合筆・分筆・換地、異なる面積根拠資料、非稲作年はすべて人のレビューが必要。研究用事前チェックの“完了”は認証審査の合格を意味しない。
