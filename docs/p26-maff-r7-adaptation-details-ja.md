## NaFT本丸へのつなぎ方

**入力層**：都道府県・品目・施策・報告された効果・現場制約・出典ページ・資料版を別項目として保持する。

**検証層**：MRV算定に利用可能な計測・係数・方法論とは別に、現場の労力、設備費、作物へのリスク、安全対策などを比較できる研究文脈を形成する。

**使ってはいけない推論**：気候適応の事例や評価記号をAG-005の排出削減係数と見なすこと、J-クレジットの認証実績と見なすこと、PDFの情報だけでシリアル権利・トークン化権限を発生させること。

## 完全性検査・原本SHA検証

GitHub Actionsでは、配布しないPDFを必要としない**台帳の整合性検査**を実施する。

    python3 tests/p26-maff-r7-adaptation-intake.test.py
    python3 scripts/p26-maff-r7-adaptation-intake.py

この既定モードは「**CATALOG_ONLY_NO_ORIGINAL_BYTES**」であり、元PDFを検証したことにはならない。

ローカルで実際の2原本を照合する場合：

    python3 scripts/p26-maff-r7-adaptation-intake.py \
      --part-2 "/local/R7_2:3_地球温暖化対策レポ.pdf" \
      --part-3 "/local/R7_3:3_地球温暖化対策レポ.pdf" \
      --out ".naft-local/maff-r7-adaptation-intake.json"

こちらは2ファイルのPDF署名、サイズ、SHA-256が一致しない場合に拒否する。アップロードされた原本とバイト列が一致したことを保証するが、国の電子署名やレポートの最新版であることまで保証しない。
