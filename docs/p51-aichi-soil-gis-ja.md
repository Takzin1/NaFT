# NaFT P51｜愛知県農耕地土壌GIS：原本属性の監査と再結合保留

2026-11-10、ユーザーが提供した `愛知県.zip` の原本ZIPを解凍し、7構成ファイルのサイズとSHA-256を照合。SHP・SHX・DBFの**2,117ポリゴン**を全件検査した。原本の属性を保持したまま、全国GX Data Atlasへ愛知県を追加する。

## 原本の来歴と保全境界

- 原本ZIP：**9,496,674 bytes**。SHA-256 `188614e4a0f369af4fb9470fd6a0af3d37bd5cfd5760c5b8170165d4d7f8d495`。
- ZIPフォルダ：`k23愛知県`（ZIP内部名の文字コードはCP932）。DBF、PRJ、SBN、SBX、SHP、SHP.XML、SHXの7ファイル、非圧縮総容量**16,068,080 bytes**。各ファイルのサイズとハッシュは研究台帳を参照。
- ESRI POLYGON（shapeType 5）、座標系GCS_JGD_2000、範囲`[136.6739375580311,34.58256795306523,137.81151037495965,35.42157312729245]`。SHP・SHX・DBFの件数はすべて2,117件。
- `KEN_1`は全件愛知県、`SICHO`は全件空欄。XMLメタデータ作成日は2017-01-17であり、2026年の現地観測データではない。
- 公開配布元の**候補**は農研機構（NARO）「日本土壌インベントリー」 https://soil-inventory.rad.naro.go.jp/download5.html 。公式愛知県ZIPと提供原本とのSHA一致、ライセンスの個別適用、再配布許可は未照合。公式に確認したかのような表記をしない。
- 公開GitHubには元SHP・DBF・ZIPを複製せず、原本のSHA-256、派生集計と検査コードのみを保持。

## JCODEと市区町村名の整合性

- JCODEは68種類、`SIKUCHOSON`の原本名称は64種類。JCODE×名称は**174組合せ**。
- 愛知県コード「23」以外のJCODEは**17ポリゴン・4組合せ**：静岡県「22」系11件、岐阜県「21」系4件、長野県「20」系2件。
- 44種類のJCODEは複数の名称に、45種類の名称は複数のJCODEに対応する。一意なJCODE×市区町村JOINを前提とした実装は不可。
- `長久手町`が原本に**26ポリゴン**。現在の市名への自動書換えはせず、旧名称であることを画面で警告する。

## 郡名GUNの検査

- GUN空欄1,697件、GUN記載420件。記載郡は、知多郡173、北設楽郡87、丹羽郡52、額田郡38、愛知郡35、海部郡27、西春日井郡6、**下伊那郡2**。
- `下伊那郡／豊田市`（牧草地2ポリゴン）は長野県の郡名が付いているため要照合。対応JCODEは`20410`、本来の市町村行政コードとしての整合が不明。原本を修正せず、誤結合防止のため正式な郡別集計へのJOINを保留。
- **郡名空欄238ポリゴン**は、同じ自治体名でGUNが記載されている別の記録が存在する。ただし内訳は**町村名148件・豊田市90件**。後者は県外郡名2件によって検出されたものであり、市の郡名空欄90件を「欠損」と断定しないこと。
- 原本GUN×名称の**80組合せ**を地目4種別に記録し、町村別の郡名補完・正規化は実施しない。

## 再現手順

`research/p51-aichi-soil-shapefile-source-v1.json`：全7ファイルのSHA、JCODE×名称174組合せ、GUN×名称80組合せ、行政異常値、科学的制約を固定。

`scripts/p51-aichi-soil-audit.py`：Python標準ライブラリのみで台帳を検証する。元ZIPを持つ環境では全バイト、DBF2,117レコード、形状ヘッダ、属性と地目集計の再現ができる。

`src/gx-aichi-soil.js`：NaFT GX Data Atlasで愛知県（prefCode=23）を選ぶと地目別カード、行政コードと郡名の警告、JCODE・郡名の原本別テーブルを表示。

`tests/p51-aichi-soil-gis.test.mjs`：台帳や警告の改変、ソース情報の欠落、JCODE・郡名集計の変化、旧名称26件、元の22都道府県表示の回帰を検査する。

公開CI：

    python3 scripts/p51-aichi-soil-audit.py audit
    node tests/p51-aichi-soil-gis.test.mjs

元ZIPを保有するローカル環境で完全再現：

    python3 scripts/p51-aichi-soil-audit.py verify '/local/private/愛知県.zip'

**公開CIのauditは「台帳の内部整合」であり、元ZIPの完全一致検証と同一ではない。** 最初の受入時には元ZIP・全7メンバー・SHPとDBF全2,117件をローカルで検査済み。

## 利用上の制約

ポリゴン件数は農地面積ha、筆数、土壌炭素の実測量、CH₄排出実測値、CO₂e削減量、認証済J-クレジット数量ではない。JCODEが1対1でなく県外値も含むため、現行行政コード、2024年水稲統計、JAXA土地被覆との自動JOINは行わず、別途ジオメトリ・境界・コード年代を照合した後に承認付きで正規化する。
