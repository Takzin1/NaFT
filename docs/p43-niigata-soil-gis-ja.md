# NaFT P43｜新潟県農耕地土壌GISの原本受入と自治体コードの非1対1対応

2026-11-09、ユーザー提供の`新潟県.zip`をオフラインで解凍し、原本ZIP・全7構成ファイルのSHA-256、SHP/SHX/DBFの図形と属性を検証。全国展開の15都道県目として、元の値を書き換えない研究用派生集計をNaFT GX Data Atlasへ追加する。

## 受入原本

- ZIP原本：**17,478,591 bytes**。SHA-256 `7e1e4877d7d7b9443b1bfc34fb71d1333fbfa4949a626837ee1fb83b6ff0246f`。
- フォルダ：`k18新潟県`。7ファイル：`k18新潟県.dbf`、`.prj`、`.sbn`、`.sbx`、`.shp`、`.shp.xml`、`.shx`。ZIP内名はCP932、全メンバの展開後合計は**26,728,304 bytes**。個別SHAは`research/p43-niigata-soil-shapefile-source-v1.json`を参照。
- ESRI POLYGON（shapeType 5）、GCS_JGD_2000（JGD2000）。SHP・SHX・DBFはいずれも**1,503レコード**。DBFの`KEN_1`全件「新潟県」、`SICHO`全件空欄。属性10列。
- bbox経度・緯度：`[137.6363794713516,36.84500778396874,139.68688147974075,38.54217014257465]`。
- XMLメタデータ作成日は**2017-01-17**であり、2026年の地目・行政境界が最新であることの証拠にはならない。

## JCODEと市区町村名称：県外コード0件でも自治体JOINは不可

- JCODEは**37種類**、市区町村名も**37種類**（新潟市の各区を含む）。ただしコード×名称の原本組合せは**86通り**で1対1対応ではない。
- JCODEの先頭2桁は**全1,503件「15」（新潟県）**で、県外コードは**0件**。県外コードの不存在を正確な自治体コードと混同しない。
- **21種類のJCODEが複数名称に、25種類の名称が複数JCODEに対応**している。例えば`15202`は長岡市以外の三条市・燕市・見附市などとも関連付いている。
- このような複数対応が生じる原因は断定しない。原GISの形状と行政境界、JCODE定義と年月日、加工・空間結合の履歴、正式自治体名の対応を確認する必要がある。
- **原本86組合せは改変せず登録**。現行市区町村別の水稲統計・経済統計やJAXA土地被覆と、無検証で行政コードJOINをしない。今後補正が必要な場合は別版の検証台帳として監査可能に残す。

## GUN（郡）情報

- `GUN`空欄は**1,345件**、郡名付きは**158件**。郡名は9種類：東蒲原郡42、岩船郡31、北蒲原郡20、中魚沼郡18、西蒲原郡13、南蒲原郡11、三島郡10、刈羽郡7、南魚沼郡6。
- **原本の郡名×市区町村名45組合せ**も地目別に研究台帳へ記載。こちらは郡別の公的面積推計ではない。
- 今回の受入時には、郡名の個別の境界・年代の完全な照合は行っていない。原本集計と正式な現行郡別データを同一視しない。

## 実装と検証

- `research/p43-niigata-soil-shapefile-source-v1.json`：原本ZIPと7ファイルSHA、bbox、86コード・名称組合せ、45郡・名称組合せ、非1対1対応と科学的利用制限。
- `scripts/p43-niigata-soil-audit.py`：手元に元ZIPがあれば、全ファイルSHA-256、SHP・SHXのレコード数、DBF全1,503件の属性、86+45組合せを別に再計算して登録値と照合する`verify`。CIでは原ZIPを公開していないため、台帳のみを検査する`audit`。
- `src/gx-niigata-soil.js`：GX Data Atlasで新潟県を選ぶと地目カード、県外JCODE0件の確認・市区町村JOIN保留警告、郡別集計、86組合せ・45組合せを展開表示。
- `tests/p43-niigata-soil-gis.test.mjs`：原本SHA、集計、コードと名称の多重対応、誤った県外コードの混入防止、画面の表示、既存14都道県の回帰をテスト。

元ZIPがあるローカル環境：

    python3 scripts/p43-niigata-soil-audit.py verify '/private/local/新潟県.zip'

原ZIPを置かない公開CI：

    python3 scripts/p43-niigata-soil-audit.py audit
    node tests/p43-niigata-soil-gis.test.mjs

**CIでのaudit成功のみをもってZIP原本の全バイト照合が実行されたと主張しない。** 受入作業のローカル環境では原本ZIPと7構成ファイルのSHA及び図形・属性1,503件を検査済み。

## 来歴と再配布の境界

公式配布元候補：農研機構（NARO）「日本土壌インベントリー／農耕地包括土壌図」 https://soil-inventory.rad.naro.go.jp/download5.html 。ただし、公式新潟県ZIPとのSHA完全一致は未確認で、今回の原本へのライセンス適用は `NOT_VERIFIED`。原GISのShapefile/DBF/ZIPは公開GitHubへ複製せず、SHAと派生集計、監査スクリプトのみ公開。

NaFTは原本土壌GISのポリゴン数からGHG排出量・土壌炭素・農地面積・CO₂e認証量を自動算出しない（`official_credit_tco2e = null`）。
