# NaFT P55｜大阪府農耕地土壌GIS原本監査

ユーザー提供の `大阪府.zip` を原本として受け入れ、ZIPと7構成ファイルのSHA-256を記録し、JGD2000のポリゴンとDBF属性764件を検証した。原本のJCODE・郡名・土壌分類の不整合は**原本値を変更せず**保持する。

## 原本と検証条件

- ZIP：**1,989,097 bytes**、SHA-256：`1f75d80027ea0d1ea2718d00f0c8d5106694991733440544f3fd040155f8909d`。
- ZIP構造：`k27大阪府/k27大阪府.dbf` ほかPRJ/SBN/SBX/SHP/SHP.XML/SHX、計7ファイル。合計解凍サイズ**3,780,922 bytes**。元ZIP名の文字コードCP932。
- 形状：ESRI POLYGON 5、GCS_JGD_2000。SHP・SHX・DBFの**764件**が一致。
- 範囲：`[135.09810442287565,34.273691451029,135.74367044727964,35.042092491955]`。
- `KEN_1`は全件「大阪府」、`SICHO`は全件空欄。XMLメタデータ作成日2017年1月17日。
- 農研機構の「日本土壌インベントリー」 https://soil-inventory.rad.naro.go.jp/download5.html は出典**候補**だが、当該公式ZIPとのSHA完全一致および再配布条件は未照合。原本Shapefile・DBF・ZIPを公開GitHubへアップロードしない。

## 地目・土壌分類

| 地目 | 原本ポリゴン数 |
|---|---:|
| 田 | 391 |
| 普通畑 | 158 |
| 牧草地 | 2 |
| 樹園地 | 213 |
| **計** | **764** |

「群コード」は12種類、「包括_統群」は43種類（**空欄を含む**）。

**土壌分類欠損2件：**
1. 0始まりレコード0：原本JCODE `27214`、原本名「千早赤阪村」、GUN空欄、樹園地1件。
2. 0始まりレコード1：原本JCODE `27214`、原本名「富田林市」、GUN空欄、樹園地1件。

ともに「包括_統群」「統群コード」「亜群コード」「群コード」がすべて空欄。元属性から補完・推計しない。

## 行政コードと郡名

- 原本名称：54種類、JCODE：57種類、JCODE×名称：**129組合せ**。
- **京都府系の府外JCODE「26」**が**7件・5組合せ**。高槻市・枚方市・茨木市・能勢町・豊能町の原本レコードに含む。
- **31コード**が複数名称に対応し、**41名称**に複数コードが対応。原本JCODEを現行自治体コードとみなした単純なJOINは禁止。
- GUN×名称：**63組合せ**。GUN空欄630件、GUN記載134件。
- 記載の郡名は南河内郡67、豊能郡35、泉南郡22、三島郡5、泉北郡5。
- **郡名空欄の要照合46件**は、同名の町村に郡名付きレコードも存在するもの。ただし、原本に郡名がない事実は必ずしも誤記を意味しない。原本の郡名は一律に補完しない。

## 再現と実装

- `research/p55-osaka-soil-shapefile-source-v1.json`：原本7ファイルのハッシュ、129組のコード×名称、63組の郡×名称、欠損2件と研究上の制約。
- `scripts/p55-osaka-soil-audit.py`：Python標準ライブラリで公開台帳の整合性監査と、ローカル環境での原本ZIPバイト照合、SHP/SHXヘッダ・DBF764レコードの完全照合を提供。
- `src/gx-osaka-soil.js`：GX Data Atlasの大阪府（コード27）に地目、JCODE、GUN、土壌分類欠損を表示。
- `tests/p55-osaka-soil-gis.test.mjs`：元属性の改変やルーティング破壊を防ぐ回帰テスト。
- `naft-app.html`、`src/gx-data-explorer.js`、`tests/run.sh`：画面とCIへの組込み。

公開CIで使用：

```bash
python3 scripts/p55-osaka-soil-audit.py audit
node tests/p55-osaka-soil-gis.test.mjs
```

元ZIPを持つ環境で実施する完全再現：

```bash
python3 scripts/p55-osaka-soil-audit.py verify '/local/private/大阪府.zip'
```

**重要：公開CIでの `audit` はハッシュ・派生件数の台帳整合性検証であり、原本ZIPバイトの再照合ではない。**

## 利用上の境界

ポリゴン件数≠農地面積ha、筆数、CH₄実測、土壌炭素量、CO₂e削減量、認証クレジット数量。JCODEの府外・多重対応、郡名空欄、土壌分類欠損を残すため、現行自治体統計や2024年水稲統計、JAXA土地被覆に対し無検証の行政コードJOINを行わない。ジオメトリ・年度・行政境界の照合と人手承認を要する。
