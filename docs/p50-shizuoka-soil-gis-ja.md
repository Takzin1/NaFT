# NaFT P50｜静岡県農耕地土壌GISの原本受入・監査（2026-11-10）

ユーザー提供の`静岡県.zip`を解凍してJGD2000の農耕地Shapefileを全件点検し、NaFT GX Data Atlas向けの派生件数を収録する。原本の**市区町村名・JCODE・郡名・区名を変更しない**。GISの一次配布元との真正性照合、再配布条件が未解決のため、公開GitHubへ原本の図形/DBF/ZIPを複製しない。

## 原本のバイト検証

- 元ZIP：10,405,578 bytes、SHA-256 `5f742daa989dac20ad00e0ab10a43ec7ee42a2f529a9b5f4fb20cb512b66b799`
- 展開先フォルダ：`k17静岡県`。7ファイル：`.dbf`、`.prj`、`.sbn`、`.sbx`、`.shp`、`.shp.xml`、`.shx`。7ファイル合計16,393,570 bytesで、各ファイルのSHA-256は研究台帳に固定。
- ShapefileはESRI Polygon（shapeType 5）、投影はJGD2000 / GCS_JGD_2000。SHP、SHX、DBFの**1,376レコードが一致**する。
- 緯度経度bbox：`[137.47834204518,34.59726879743675,139.1394105471396,35.43550077096272]`。
- XMLメタデータ作成日2017-01-17。これは2026年現在の土地現況を示す時点ではない。
- 出典候補：農研機構（NARO）の日本土壌インベントリー https://soil-inventory.rad.naro.go.jp/download5.html 。ただし、公式静岡県ZIPとのSHA一致および適用ライセンス・二次配布許諾は未検証。

## 県外JCODEと市区町村名の揺れ

- JCODEは46種類、`SIKUCHOSON`は43種類、**JCODE×名称104組合せ**。28のJCODEに複数名称、34の名称に複数JCODEが結び付く。
- 静岡県の「22」系ではない県外JCODEが**4ポリゴン**（神奈川県「14」系3件・山梨県「19」系1件）。原本は勝手に直さず要照合にする。
- 原本に旧浜松市の`中区`、`東区`、`西区`、`南区`、`北区`、`浜北区`等が含まれる。2024年の区再編を加味した現行の行政コードへの置換は未実施。原本値と現行境界・コードを別のバージョンで突合する必要がある。

## 郡名GUNの品質

- **GUN×市区町村名56組合せ**。原本GUNは空欄1,187件、南都留郡1、周智郡30、榛原郡22、田方郡24、賀茂郡86、足柄下郡3、駿東郡23。
- **県外の郡名4件**：神奈川県に属する「足柄下郡」3件（原本の名称は三島市・熱海市・裾野市）、山梨県に属する「南都留郡」1件（富士宮市）。県外JCODE4件と機械的に同一レコードと決めつけない。
- 同一市区町村名でGUNの記入済みレコードが存在する一方、GUNが空欄のレコードが**13の名称組合せ・計137件**。この指標は必ずしも誤記とは限らない。市のように郡名空欄が正当な場合もあるため、「補完候補」ではなく「要照合」として保存する。
- 一つの市区町村名に複数の**非空**GUNが付くケースは0。原本を自動補正しない。

## 再現方法

公開CIは派生台帳のみ検査し、元ZIPのハッシュ検証完了とは混同しない。

```bash
python3 scripts/p50-shizuoka-soil-audit.py audit
node tests/p50-shizuoka-soil-gis.test.mjs
```

元ZIPが利用できる環境では7ファイル全ハッシュ、図形ヘッダー、DBF全1,376レコード、JCODE・GUN組合せをバイトから再計算する。

```bash
python3 scripts/p50-shizuoka-soil-audit.py verify '/private/original/静岡県.zip'
```

- `research/p50-shizuoka-soil-shapefile-source-v1.json`：元ZIPと7ファイルのSHA-256、104行政コード組合せと56郡名組合せ、出典・科学上の制約。
- `src/gx-shizuoka-soil.js`：静岡県選択時の地目カードと要照合注記・2種の原本一覧。
- `tests/p50-shizuoka-soil-gis.test.mjs`：集計の整合、県外JCODE、郡名の空欄と県外の郡名、UI回帰。

## 科学上の制約

ポリゴン件数を農地面積ha・地番の筆数・土壌炭素量・CH₄実測・CO₂e排出削減量・認証済クレジットに変換しない。2024年水稲統計やJAXA土地被覆との行政コードによる無検証な自動JOINは行わず、公式自治体境界・改編年月・コード体系のすり合わせが終わるまで保留とする。
