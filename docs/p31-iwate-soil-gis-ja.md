# NaFT P31｜岩手県 農耕地土壌GISの原本検証と研究用集計

2026-11-09。ユーザー提供「岩手県(1).zip」を実際に解析。
北海道（P29）・青森県（P30）とは独立した土壌GISデータソースとして登録した。
既存の2024年米統計・JAXA衛星土地被覆・CH₄観測と自動統合しない。

## 原本のデータ仕様

- 原本ZIP：15,089,311バイト、SHA-256 65e6493313866af25ee5695ef2e1882c4bf9f5cbd12a798c2fb394027d1315ff。
- ZIP内7ファイル：k03岩手県/k3岩手県.dbf、.prj、.sbn、.sbx、.shp、.shp.xml、.shx。展開後合計23,795,048バイト。
- 内部ファイル名は旧Shift-JIS（CP932）で記録されており、復号して検証した。
- 地理形状はPolygon 2,149件。SHP・SHXで全件数が一致、Python pyshpで2,149形状の読み取りを確認。
- 空間参照はGCS_JGD_2000（JGD2000）。原本bboxは東経140.71055549154266〜142.0391644869843、北緯38.72421929402586〜40.44934932676321。
- 原本Esriメタデータ作成日2017-01-17。2026年の現地調査や最新地目とは主張できない。
- 「群コード」17種、「包括_統群」85種。県名KEN_1は全件「岩手県」。
- 33市町村コード（5桁JCODE）。SICHOは全件空欄のため、振興局別ではなく市町村別に集計する。
- 滝沢の原本名称は「滝沢村」（JCODE 03305）。現行表記の「滝沢市」へ無根拠に自動置換しない。原本の自治体名と調査対象年代には歴史的ずれがあり得る。

## GitHubの反映内容

- research/p31-iwate-soil-shapefile-source-v1.json：原本ZIP・全7構成ファイルの長さとSHA-256、bbox、地目内訳、33市町村×4地目の集計、原本旧名称情報。
- scripts/p31-iwate-soil-audit.py：Python標準ライブラリだけで、原本ZIPとSHP/SHX/DBFの全バイト、座標とDBF全2,149件、市町村別集計をオフラインで照合。
- src/gx-iwate-soil.js：GX Data Atlasで岩手県を選んだときのみ、地目別概要と市町村一覧を読み取り専用表示。
- tests/p31-iwate-soil-gis.test.mjs：集計・ハッシュメタデータ・画面出し分け・変造の検知・旧名称保持をテスト。

完全原本検証（手元にZIPがあるときのみ）：

    python3 scripts/p31-iwate-soil-audit.py verify '/local/private/岩手県(1).zip'

登録台帳の整合性確認（GitHub Actions CIでも実行）：

    python3 scripts/p31-iwate-soil-audit.py audit
    node tests/p31-iwate-soil-gis.test.mjs

GitHub CIには原本ZIPを含めない。従ってCIのaudit成功は原本自体の再検証成功を意味しない。原本は本作業環境で別途SHA・形状・属性を検査している。

## 科学的・公開上の制約

- 原ファイルからCH₄実測量、CO₂e換算削減量、圃場別排出係数、土壌炭素量は導けない。
- 2017年メタデータの土壌分類と2024年の水稲作付・収穫データは別概念。圃場境界との幾何学的照合や分類精度・土地の年次更新検証は未実装。
- 原GISの配布元と再配布ライセンスの確認ができていないため、元Shapefile/DBF/ZIPは公開GitHubに複製せず、ハッシュと派生集計のみ公開する。
- J-クレジット等の正式な削減量・クレジット発行・認証に使用できるデータではない（official_credit_tco2e=null）。
