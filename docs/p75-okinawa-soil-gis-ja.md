# NaFT P75｜沖縄県農耕地土壌GIS：原本監査・行政属性の要照合

## 原本ZIPと公開範囲

`沖縄県.zip`（5,541,529 bytes、SHA-256 `68cb4b0950aaadc07ce1e98bf52497f66b34ed595cbec6b0b511f87b1310c68f`）には `k47沖縄県` ディレクトリ下にDBF/PRJ/SBN/SBX/SHP/SHP.XML/SHXの7ファイルがある（展開計8,536,300 bytes）。DBF/SHP/SHXの**663レコード**が一致し、SHP/SHXの全レコードの番号・オフセット・バイト長に不整合なし。ESRI POLYGON（shapeType 5）、GCS_JGD_2000。原本XML作成日は2017-01-17。

出典候補：農研機構「日本土壌インベントリー」 https://soil-inventory.rad.naro.go.jp/download5.html 。公式配布ZIPとの同一性・発行者認証・再配布許諾は未確認。原本ZIP・SHP・DBF・個別地物の座標は公開GitHubへコミットせず、原本・構成ファイルSHA-256、非座標の派生集計、監査方法だけを保存する。

## 行政属性の要照合

- `KEN_1` は全663行が沖縄県、`SICHO` は全件空欄。市町村名41種類、JCODE41種類、JCODE×市町村名75組、郡名GUN×市町村名55組。
- **県外系JCODEは0件**。ただしJCODE19種類が複数自治体名、自治体名16種類が複数JCODEに対応しているため、現行市町村統計との自動JOINは保留。
- **GUN（郡名）空欄272件**。うち同じ市町村名の郡名記載レコードが別に存在するものが52件。郡名の空欄を推測補完しない。
- **南風原町と与那原町**には非空欄郡名「中頭郡」「島尻郡」の両方が記載されている。異なる郡のレコードを勝手に修正・削除しない。
- 石垣・宮古・八重山・大東・沖縄本島等を含む島しょ地域のポリゴン集計。個別地物座標や農地面積は公開していない。

## 検証

- `research/p75-okinawa-soil-shapefile-source-v1.json`：原本ZIP・7ファイルのSHA、サイズと派生集計を固定。
- 公開CI：`python3 scripts/p75-okinawa-soil-audit.py audit` および `node tests/p75-okinawa-soil-gis.test.mjs`。原本ZIPを使わない監査台帳の構造・整合・誤補正防止を検査。
- 原本を適法に利用できるローカル環境：`python3 scripts/p75-okinawa-soil-audit.py verify /private/沖縄県.zip`。ZIP・7ファイルのSHA、SHP/SHX全663件・DBF全663行のCP932原本属性と集計を再検証。
- GX Data AtlasではprefCode `47` で地目カード、JCODE×市町村名75組・GUN×市町村名55組、行政属性の注意書きを表示。

**科学的限界**：ポリゴン件数は農地面積ha、CH₄/CO₂eの排出・削減量、認証済み炭素クレジット量ではない。圃場別MRVには地物の合法的な利用・境界・年代・正式方法論・証憑・HITL・第三者検証が別途必要。
