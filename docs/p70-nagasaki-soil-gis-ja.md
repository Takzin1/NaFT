# NaFT P70｜長崎県農耕地土壌GIS：原本監査・行政属性の要照合・安全な再利用

## 元ZIPと公開範囲

2026-11-10提供の `長崎県.zip`（7,239,387 bytes、SHA-256 `b164c6fdbdea997356b05f6658005d2acc855916d2837ec459aed994fc764b1e`）。内部の `k42長崎県` にDBF/PRJ/SBN/SBX/SHP/SHP.XML/SHX計7ファイル、展開計11,235,300 bytes。SHP・SHX・DBFはすべて**863件**で、SHP/SHXの全863件のレコード番号・位置・バイト長が一致。ESRI POLYGON (shapeType 5)、GCS_JGD_2000、XML作成日2017-01-17。

出典候補：農研機構「日本土壌インベントリー」 https://soil-inventory.rad.naro.go.jp/download5.html 。公式ZIPとのバイト単位での同一性、配布元認証、著作権・再配布許諾は未確認。**元ZIP・SHP・DBF・地物単位の座標を公開リポジトリに置かず**、元ZIPと全7ファイルのSHA-256、非座標の派生集計、監査方法だけを登録する。

## 原本行政属性と要照合

- 原本DBFの全863件でKEN_1は「長崎県」、SICHOは全件空欄。市町村名21種類、JCODE26種類、JCODE×名称46組、GUN×名称30組。
- **佐賀県系JCODE（41系）19件**：松浦市（41205）、波佐見町（41206・41401）、東彼杵町（41209）、佐世保市（41401）、諫早市（41441）。行政コードを長崎県42系へ自動補正しない。
- 10種類のJCODEが複数名称に、14種類の市町村名が複数JCODEに対応。現行市町村との自動JOINは保留する。
- **郡名GUNが680件空欄**。同名で非空欄GUNが別途存在するものは159件。佐賀県系の郡名「藤津郡」6件（諫早市）、「西松浦郡」5件（佐世保市2件・波佐見町3件）が含まれる。
- 波佐見町は「東彼杵郡」「西松浦郡」という非空郡名の2通りがある。原本を無断修正・補完しない。

## 検証と画面

- `research/p70-nagasaki-soil-shapefile-source-v1.json`：ZIPと7構成ファイルのSHA-256・サイズ、地目別件数、JCODE/郡名×市町村名の派生集計、未解決の行政コード・郡名対応。
- 公開CI：`python3 scripts/p70-nagasaki-soil-audit.py audit` と `node tests/p70-nagasaki-soil-gis.test.mjs`。公開CIには元ZIPを置かず、台帳整合のみ検証。
- 許諾済みローカル環境：`python3 scripts/p70-nagasaki-soil-audit.py verify /private/長崎県.zip`。元ZIPと7ファイルの全バイトSHA、SHP/SHX全863件、DBF全863行のCP932属性と派生集計を再現検証。
- GX Data AtlasはprefCode `42` のとき地目別件数、JCODE×名称46組、GUN×名称30組、県外系コード・郡名の要照合を表示する。

**科学・制度上の制限**：ポリゴン件数は農地面積ha、土壌炭素量、CH₄/CO₂e削減量、認証済み炭素クレジット発行量を意味しない。圃場単位のMRVで使用するには、境界・年代整合、適用方法論、一次証拠、人による判断、第三者検証が別途必要。
