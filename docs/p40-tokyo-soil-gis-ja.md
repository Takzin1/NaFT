# NaFT P40｜東京都農耕地土壌GISの原本検証・島しょ支庁・行政コード不整合

2026-11-09にユーザー提供「東京都(1).zip」をオフラインで実際に解凍。元ZIPおよび7構成ファイルのバイト数・SHA-256、全472件のShapefile図形・DBF属性を検査した。NaFT GX Data Atlasで表示する研究用の派生集計として取り込む。原GISの図形は公開GitHubには追加しない。

## 原本と測定済みの仕様

- 元ZIP：**1,227,836 bytes**、SHA-256：`b4dcede3f7664f4366d7d6ab5ead2c06314602c8c9d691a946d90984af3d9c1e`。
- フォルダ：`k13東京都`。構成7ファイル：`k13東京都.dbf`、`.prj`、`.sbn`、`.sbx`、`.shp`、`.shp.xml`、`.shx`。原本はCP932の日本語名を使用。展開後の合計は**2,371,330 bytes**。各SHA-256は研究台帳JSONに固定。
- Esri Shapefile POLYGON（shapeType=5）、JGD2000（GCS_JGD_2000）。SHP・SHX・DBFの件数はいずれも**472件**で一致。全図形をpyshpで走査して確認した。
- 原本SHPのbbox（経度・緯度）は `[138.9725498740143, 33.06049025736573, 139.85639982273338, 35.84624892212051]`。島しょ部も含むため緯度範囲が広い。
- DBFの`KEN_1`は472件すべて東京都。XMLメタデータ作成日は**2017-01-17**。これは2026年の農地現況、測量日、行政区域の最新性を意味しない。

## 東京特有のSICHO（支庁）・GUN（郡）を保持

- `SICHO`（原本の支庁）内訳：空欄451件、**大島支庁9件、三宅支庁6件、八丈支庁6件**。島しょ部の支庁名付き記録は合計21件。
- 支庁名付き市町村：大島支庁＝大島町・利島村・新島村・神津島村、三宅支庁＝三宅村、八丈支庁＝八丈町。
- `GUN`（郡）：空欄440件、**西多摩郡32件**。
- 市区町村名は43種類だが、これはファイルに掲載された名称数であり、東京都の全区市町村数ではない。特定の市区町村の掲載がなかったとしても、そこでの農耕地の不存在を示すものではない。

## JCODE（行政コード）と市区町村名の不整合

- 行政コード（JCODE）**47種類**、名称43種類、両者の組合せは**87通り**。JCODE23種類が複数名称に、名称26種類が複数JCODEに対応している。
- 東京都「13」と異なる**埼玉県「11」系コード**を持つポリゴンが**15件／8コード・名称組合せ**。例：`11225／青梅市`、`11229／練馬区`など。これは原本の属性の照合が必要であることを示すが、原因は未確認。
- 原本の各行を勝手に上書きしたり、現行市区町村コードへ自動補正しない。研究台帳には**87組合せの原本集計**を保存し、NaFT画面では「要照合」を明示する。
- 現行の自治体境界、農林業センサス、2024年水稲統計、JAXA土地被覆などとJOINする前に、GIS位置、自治体境界、行政コードの年代、原本加工履歴を確認する。

## 公開ファイルと監査

- `research/p40-tokyo-soil-shapefile-source-v1.json`：元ZIPと全7ファイルSHA、土壌分類、87組合せ、島しょ支庁・西多摩郡の派生集計、利用制約。
- `scripts/p40-tokyo-soil-audit.py`：元ZIPのバイトSHA、ZIPの7ファイルSHA、SHP/SHX、DBF全472件、SICHO・GUN・87組合せを再照合できるオフライン監査。公開CIでは原ZIPを持たないので台帳監査のみ。
- `src/gx-tokyo-soil.js`：GX Data Atlasで東京都を選択したときに4地目カード、県外JCODE警告、島しょ部の支庁別表、87組合せの表を表示。
- `tests/p40-tokyo-soil-gis.test.mjs`：台帳とJSデータの一致、県外コード、島しょ支庁、画面の県コードによる選別、既存11都道県表示保持をテスト。

元ZIPを保持しているローカル環境での完全再照合：

    python3 scripts/p40-tokyo-soil-audit.py verify '/local/private/東京都(1).zip'

原ZIPを保存しない公開CIでの台帳検証：

    python3 scripts/p40-tokyo-soil-audit.py audit
    node tests/p40-tokyo-soil-gis.test.mjs

**CI上のaudit成功を原ZIPのSHA・DBF全件再照合成功と混同しない。** 受入時には別のオフライン環境で原ZIP全バイトのSHA・構成ファイル全件SHA・図形・属性を直接確認した。

## 出典候補と科学的・権利的境界

原資料の配布元候補は農研機構（NARO）「日本土壌インベントリー／農耕地包括土壌図」：https://soil-inventory.rad.naro.go.jp/download5.html 。ただし公式の東京都ZIPを取得して今回の原本とSHAを照合できていないため、**今回の具体的なZIPへのライセンス適用はNOT_VERIFIEDのまま**とする。

元GISのShapefile/DBF/ZIPは公開GitHubへ複製せず、ハッシュと研究用派生集計のみを公開。土壌図のポリゴン数から農地面積ha、土壌炭素量、メタン排出量、CO₂e削減量、認証済みクレジット量を算出しない（`official_credit_tco2e=null`）。
