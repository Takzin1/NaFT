# NaFT P41｜千葉県農耕地土壌GIS原本受入・県外JCODE・郡名GUN不整合

2026-11-09、ユーザー提供の `千葉県.zip` を実際に解凍し、元のZIPハッシュ・全7構成ファイルSHA-256・SHP/SHX/DBFの全1,907件を検証した。千葉県はNaFTの関東編第6弾。**地目別ポリゴン件数を面積や排出削減量とみなさない**。

## ZIP原本とGISの概要

- 元ZIP：15,034,521 bytes。SHA-256：`b7bd3c536c25d8df5f4f3b652a6728db0d31178f644faf014415f01ce854ae7f`。
- 日本語名CP932由来の元フォルダ：`k12千葉県`、7ファイル：`k12千葉県.dbf`、`.prj`、`.sbn`、`.sbx`、`.shp`、`.shp.xml`、`.shx`。展開総計23,460,976 bytes。各ファイルサイズ・ハッシュは研究台帳JSONに記録。
- JGD2000（GCS_JGD_2000）、Esri Shapefile POLYGON型5。SHP・SHX・DBFはいずれも1,907件、pyshpで全図形・属性を検査。
- 原本bbox（経度・緯度）：`[139.753883054109,34.903491240950544,140.865870254935,36.10150344929939]`。
- DBF `KEN_1` はすべて「千葉県」。`SICHO` はすべて空欄。原本XMLメタデータ作成日2017-01-17。これは2026年の農地現況を保証しない。
- 土壌の「群コード」13種類、「包括_統群」55種類。

## 原本の行政コードと市区町村名の不整合

- 原本にある市区町村名は**57種類**（千葉市の区を含むため、千葉県の57自治体という意味ではない）。JCODEは**63種類**、その組合せは**179通り**。
- 42種類のJCODEが複数名称に、49種類の名称が複数JCODEに対応する。
- KEN_1は千葉県だが、県外のJCODEを持つレコードが**8ポリゴン／6組合せ**存在する。茨城県「08」系が7件、埼玉県「11」系が1件。
- 原本に旧名称「大網白里町」が**72ポリゴン**掲載されている。名称を現行「大網白里市」へ自動置換しない。
- 元の値のずれが発生した原因は未確認。GIS座標・公式行政境界・コード設定時点・原本の加工履歴を確認するまで、JCODEに基づく市区町村統計の自動JOINを停止する。

## 千葉県で見つかったGUN（郡）属性の不整合

- GUNの原本集計：空欄1,514、印旛郡22、夷隅郡36、安房郡24、山武郡92、**猿島郡1**、長生郡153、香取郡65（合計1,907件）。
- **原本の1レコード：「JCODE 08542／野田市／猿島郡／普通畑」**。KEN_1は千葉県だが、「猿島郡」は茨城県の郡名であり、市名と県名の組合せには不整合がある。
- 県外コードも該当するため、境界近傍での属性付与などの問題が疑われるが、原因は断定しない。原本属性を消去・訂正せず、GUNの来歴も研究台帳へ記録する。
- GUN空欄を勝手に補完しない。郡名が表示されていても公式な郡別面積/面積比統計ではない。

## NaFT P41の実装

- `research/p41-chiba-soil-shapefile-source-v1.json`：元ZIPと7メンバのSHA、地目・土壌分類・全179 JCODE×市区町村名組合せ、GUN集計と猿島郡の不整合、研究制約を記録。
- `scripts/p41-chiba-soil-audit.py`：元ZIPが手元にある場合はSHA・全メンバ・SHP/SHX/DBF・179組合せ・GUN・要照合1件を元のDBFから再検証。公開CIでは原ZIPを保持せず台帳の`audit`のみ実施。
- `src/gx-chiba-soil.js`：GX Data Atlasで千葉県を選ぶと地目カード・行政コードと郡名不整合警告・GUN別の原本集計・179行の表を表示。
- `tests/p41-chiba-soil-gis.test.mjs`：SHA/集計値、県外コード・旧名・郡名警告、表示県コード分岐、既存12都道県機能の回帰を確認。

原ZIPを保持するローカル環境で原本バイト単位を照合：

    python3 scripts/p41-chiba-soil-audit.py verify '/local/private/千葉県.zip'

公開CIの監査（元ZIPを必要としない）：

    python3 scripts/p41-chiba-soil-audit.py audit
    node tests/p41-chiba-soil-gis.test.mjs

**CIの`audit`成功は、GitHub Actionsで原ZIPの`verify`を実行したという意味ではない。** 受入時に原ZIPと全メンバ・SHP/SHX/DBFを独立したローカル環境で検査済み。
