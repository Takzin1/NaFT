## 計算式1：水稲収穫量の単位恒等式（NaFTで導出した研究上の照合式）

\[
\text{玄米収穫量の参考値[t]}=\frac{\text{水稲作付面積[ha]}\times\text{10a当たり収量[kg]}}{100}
\]

理由は、1ha = 10×10a、1t = 1000kgであるため。**公式に公表された収穫量をこの式で上書きしない**。作付面積や単収が丸めてある場合、国の正式結果と多少差がある。

例：2024年の福島県、62,700ha × 569kg/10a ÷ 100 = **356,763t**。公式転記は**356,800t**、差は37t。研究上の単位整合の照合として許容するが、それは県内のCH₄排出量を意味しない。

一方、47行のうち**徳島県・高知県**の行は、読み取った面積・単収からの単純計算と公表収穫量に本ツール基準（500t以上かつ公表値の2%超）の差があり要照合とした。原表の数字、分期栽培、集計方法、PDFの読み違いなどの原因を再確認するまでは**勝手に修正も算定採用もしない**。

## 計算式2：AG-005 v1.0旧版で説明される参考式

原出典： [農林水産省・AG-005 ver1.0](https://www.maff.go.jp/j/press/kanbo/b_kankyo/attach/pdf/230301-2.pdf) p.1〜3。

\[
ER=EM_{BL}-EM_{PJ}
\]
\[
EM=\sum_{s}(A_s\times EF_{s,\mathrm{CH4-C}})\times\frac{16}{12}\times GWP_{\mathrm{CH4}}\times 10^{-3}
\]

- \(A_s\)：層別の作付面積[ha]。
- \(EF_{s,\mathrm{CH4-C}}\)：該当条件・年のメタン**炭素換算**排出係数[kg-CH4-C/ha/年]。kg-CH₄と混同しない。
- \(16/12\)：メタン中の炭素質量からCH₄全体の質量への変換。
- \(GWP_{\mathrm{CH4}}\)：用いるインベントリ年度・制度条件に応じた温暖化係数。**NaFTに制度既定値をハードコードしない**。
- \(10^{-3}\)：kgからtへの換算。

`scripts/p9-prefecture-rice-source-guard.mjs preview` は**過去2年以上の中干し日数、作期回数、7日延長の予備判定**とこの数式の参考計算を行う。**旧版に対応する数値例の再現**であり、2026年の現行正式方法論・採択係数・圃場実測・監査人承認を主張しない。

### 合成例だけの再現

`fixtures/p9-synthetic-ag005-v1-preview.json` には研究上だけの例として、福島県・面積2ha、排出係数100と70（kg-CH₄-C/ha/年）、**仮置きのGWP28**、過去中干し8日・9日、実施16日を設定した。これらの値は**公式係数でも対象農家の実データでもない**。

- 慣行中干し平均：8.5日
- 延長：16−8.5 = **7.5日**（7日間の参考条件だけを通過）
- 基準排出参考値：**7.466667tCO₂e**
- 実施後参考値：**5.226667tCO₂e**
- 差：**2.24tCO₂e（合成・旧版参考計算）**。認証されたクレジット数量は**null**。

## 使用方法

```bash
node scripts/p9-prefecture-rice-source-guard.mjs audit
node scripts/p9-prefecture-rice-source-guard.mjs prefecture 07
node scripts/p9-prefecture-rice-source-guard.mjs preview \
  fixtures/p9-synthetic-ag005-v1-preview.json \
  > /tmp/p9-legacy-preview.json
node scripts/p9-prefecture-rice-source-guard.mjs verify \
  fixtures/p9-synthetic-ag005-v1-preview.json \
  /tmp/p9-legacy-preview.json
node tests/p9-prefecture-rice-source-guard.test.mjs
bash tests/run.sh
```

`audit` は**47県の統計値を使用した品質照合**、`prefecture 07` は福島県の出典と値、`preview` は**入力者が明示した旧版参考係数だけ**から再計算し、出典明示・制度未確認・正式認証値 null を保持する。未知の県コード、混在年、不正な面積やEF、旧版を現在版と装った指定、原典のハッシュ認証偽装、算定レシート改変は拒否する。
