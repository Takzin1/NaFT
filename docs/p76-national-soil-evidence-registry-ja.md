# P76｜National Soil Evidence Registry v1 — 全国47都道府県の監査統合

## 何を完成させたか

全国47都道府県（P29〜P75）の農耕地土壌GIS由来の**非座標の派生集計**を、県別原本監査台帳から独立に再構成できる全国レジストリへ統合した。元ZIP・SHP・DBF・個別地物座標は含めない。

- 全国の原本由来ポリゴン件数：**60,863件**。農地面積haではない。
- 地目別合計：田22,755件、普通畑20,726件、牧草地5,327件、樹園地12,055件。
- 全国47県すべての提供ZIPのSHA-256を記録。**公式配布ZIPとバイト単位で照合済みの県は0県**。
- 再配布許諾の個別確認済みは**0県**。各県別原本台帳の利用条件フラグは `NOT_VERIFIED`。NaFTのMITライセンスが元GISに自動適用されることはない。
- JCODEと市町村名の不整合・郡名空欄・土壌属性欠損を明示し、現行自治体への無条件な自動JOINを禁止。

## 未記録をゼロに変換しない

都道府県の台帳は異なる開発時期のスキーマで作られた。品質項目が台帳にないときは `null`（未記録）とし、明示的に `0` と報告された場合と区別している。

| 品質項目 | 報告あり | 未記録 | 報告済み県の値の合計 |
|---|---:|---:|---:|
| 県外系JCODEポリゴン | 37県 | 10県 | 365件 |
| 郡名GUN空欄ポリゴン | 16県 | 31県 | 10,449件 |
| 土壌群欠損ポリゴン | 24県 | 23県 | 5件 |

右端は**報告済み県だけの合計**であり、全国の真の異常件数を示す数字ではない。未記録の県が「異常0件」という意味ではない。

## 実装と利用

- 全国レジストリ：`research/p76-national-soil-evidence-registry-v1.json`
- 独立再構成・監査：`scripts/p76-national-soil-registry-audit.mjs`
- ブラウザ表示：`src/gx-national-soil-registry.js`
- 回帰テスト：`tests/p76-national-soil-registry.test.mjs`
- 入口：GX Data Atlas（`naft-app.html#/gx-data`）内の全国監査セクション。県選択に追従してZIP SHA-256・地目・要照合情報を表示し、47県の出典台帳へ遷移できる。

```bash
node scripts/p76-national-soil-registry-audit.mjs --check
node tests/p76-national-soil-registry.test.mjs
# 将来、元の県別台帳を更新した場合
node scripts/p76-national-soil-registry-audit.mjs --write
```

監査スクリプトは47個の県別JSONから全国レジストリを直接組み立て直し、原本ZIP・構成7ファイルのハッシュ形式、原本非公開フラグ、県コード、地目合計、行政属性例外の件数と未報告状態を照合する。台帳の変更・改変やコピーの食い違いがあれば `--check` は失敗する。

Web画面は全国スナップショットと同内容の**監査済み静的JSバンドル**を読み込む。追加ネットワーク通信は行わず、県別47ZIPや原本地物もブラウザに取り込まない。`--check` は静的JS・全国JSON・47県の元台帳を三者照合し、`--write` は全国JSONと静的JSを同時再生成する。整合性違反時は全国表示を停止する。

## 残る実務検証

配布元の公式ZIPバイト照合と個別の権利確認、品質項目が未記録の県の追完、行政コードと境界の整合確認、筆ポリゴン/圃場IDへの合法的な接続、AG-005等の方法論版と一次証拠の取得を別PRで進める。

**このレジストリは農地面積、CO₂e削減量、認証済み炭素クレジットの自動算定・発行を示さない。**
