# NaFT P74｜鹿児島県農耕地土壌GIS：原本監査・行政属性の要照合・安全な再利用

## 原本ZIPと公開範囲

2026-11-10提供の `鹿児島県.zip`（14,692,127 bytes、SHA-256 `26b91128ec49d96d48285157295e5aef2bc3b7fe464c24ac0349493bafc8e817`）。内部の `k46鹿児島県` にDBF/PRJ/SBN/SBX/SHP/SHP.XML/SHXの7ファイル（展開計22,462,084 bytes）。DBF/SHP/SHXの**1,549件**が一致し、SHP/SHX全件のレコード番号・オフセット・長さも整合。ESRI POLYGON（shapeType 5）、GCS_JGD_2000、XML作成日2017-01-17。

出典候補：農研機構「日本土壌インベントリー」 https://soil-inventory.rad.naro.go.jp/download5.html 。公式配布ZIPとのバイト同一性、配布者認証、著作権・再配布許諾は未確認。**原本ZIP、SHP、DBFおよび個別地物座標を公開リポジトリに置かず**、原本ハッシュ・非座標の派生集計・検証方法だけを残す。

## 原本行政属性と要照合

- KEN_1は全1,549行が鹿児島県。SICHOは全件空欄。市町村名41種類、JCODE45種類、JCODE×名称90組、GUN×名称51組。
- **県外系JCODE26件**：熊本県系43コードが伊佐市に2件（`43205`：牧草地1・樹園地1）、宮崎県系45コードが24件（`45202`曽於市19件・霧島市1件、`45207`志布志市1件、`45209`湧水町3件）。行政コードの自動補正はしない。
- JCODE23種類が複数名称、自治体名27種類が複数JCODEに対応。現行市町村統計との無条件自動JOINは禁止。
- **郡名GUNの空欄1,039件**。うち同名で郡名記載のある原本が存在するものは63件。県外由来の郡名は確認されなかった。
- **東串良町**では非空欄郡名が「曽於郡」「肝属郡」の2つに分かれている。元値を推測で置き換えず、要照合として保持する。
- 島しょ部を含む原本の集計件数であり、座標や市町村境界のジオメトリ、面積は公開しない。

## 監査とGX Data Atlas

- `research/p74-kagoshima-soil-shapefile-source-v1.json`：元ZIPと7構成ファイルのSHA-256、地目・原本行政属性の集計、未解決コード・郡名の要照合。
- 公開CI：`python3 scripts/p74-kagoshima-soil-audit.py audit` と `node tests/p74-kagoshima-soil-gis.test.mjs`。元ZIPが公開CIにないため、公開CIは台帳整合のみ検査する。
- 原本ZIPを適法に持つローカル環境：`python3 scripts/p74-kagoshima-soil-audit.py verify /private/鹿児島県.zip`。ZIP/7構成ファイルの全バイトSHA、SHP/SHX全1,549レコード、DBF全1,549行のCP932属性と派生集計を再現検証。
- GX Data AtlasではprefCode `46` に地目別カード、JCODE×市町村名90組、郡名×市町村名51組の表と要照合情報を表示する。

**科学・制度上の限界**：ポリゴン件数は農地面積ha、土壌炭素量、CH₄排出・CO₂e削減量、認証済み炭素クレジット発行量ではない。圃場単位のMRVには合法的な境界・年代、方法論・一次証拠・HITL・第三者検証が別途必要。
