## 実装

- `src/gx-rice-history.js` に各県の **D/E/F/G/I/J** 6列の元セルとExcel行番号を保持（計94県・年レコード、564数値）。
- D=子実用作付面積（ha）、E=子実用単収（kg/10a、1.70mm）、F=子実用収穫量（t、1.70mm）、G=生産者ふるい目幅別単収、I=主食用面積、J=主食用収穫量。
- `#/gx-data` に2023・2024年同一都道府県の原本実数とD/E/F列だけの同一範囲差分を表示。各47県を県ドロップダウンと連動。福島県は2023年 58,400ha / 561kg/10a / 327,600t、2024年 62,700ha / 569kg/10a / 356,800t。
- 主食用収穫量Jは**異なる母集団・測定条件の取り違えを避けるため**年差をUIで算出しない。2025年P12の生産者ふるい上主食用収穫量との直接比較もブロック。
- 元ExcelバイナリはPublic GitHubに転載しない。SHA-256・サイズ・セル座標と取り込んだ数値を保持する。
- 47県の丸め済公表値の単純合算は全国公表値と完全一致しない（2023：7,164,715 vs 7,165,000t、2024：7,344,993 vs 7,345,000t）。公式値を上書きしない。
- 2023/24の1.70mm子実用収穫量（F）は同一定義のため前年比を比較可能。**この年差はメタン排出削減やクレジット量ではない**。2025年P12の各種主食用指標と自動混合しない。

## 原本再照合とテスト

```bash
python3 scripts/p13-estat-2023-2024-original-replay.py /private/f002-05-001.xls /private/f002-06-001.xls
node tests/p13-estat-2023-2024-original-source.test.mjs
bash tests/run.sh
```

原本監査器は登録済SHA・全94原県名行・564数値セル・全国10数値セルを照合し、一つでも異なれば停止する。
この登録だけで正式AG-005方法論、現場の温室効果ガス排出、削減量、第三者承認を証明しない。
