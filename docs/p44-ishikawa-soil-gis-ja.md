# NaFT P44｜石川県農耕地土壌GIS原本受入・行政コードと郡名の照合保留

2026-11-10、ユーザーからアップロードされた`石川県.zip`を実際に解凍し、全7構成ファイルのSHA-256、Shapefile図形・属性**630件**を検証した。石川県はNaFTのP44。県単位の位置づけは北陸の研究用GIS追加であり、富山県や福井県が登録済みであることは意味しない。

## 原本の来歴と構造

- 原本ZIP：**3,522,275 bytes**、SHA-256：`84cb6318af859e65827319e613baa60ce9d0c2913d859dce3e9c3f1c0050f9ad`。
- ZIP内フォルダ：`k20石川県`、構成7ファイル：`k20石川県.dbf`、`.prj`、`.sbn`、`.sbx`、`.shp`、`.shp.xml`、`.shx`。元ZIPの日本語ファイル名はCP932。非圧縮の合計は**5,802,534 bytes**。7ファイルすべてのSHA-256は研究台帳に保持。
- POLYGON（Shapefile shapeType=5）、JGD2000（GCS_JGD_2000）。SHP・SHX・DBFはいずれも**630件**で一致。全図形・DBF属性をpyshpで走査。
- bbox：`[136.2509378621368, 36.16399276652885, 137.35953704185152, 37.528077919581506]`。
- 元DBFの`KEN_1`は630件すべて「石川県」、`SICHO`は全件空欄。XMLメタデータ作成日2017-01-17。ただしこの日付は全ポリゴンの現況調査日を保証しない。
- `k20`は元GISのファイル名コードであり、自治体コードの「17」（石川県）と同一体系とは限らない。両者を取り違えない。

## JCODE×市町村名の原本不整合

- **JCODE22種類・名称19種類・コードと名称の組合せ47通り**。
- 石川県コード「17」ではなく、富山県系の「16」コードが**5件／3組合せ**（`16205／宝達志水町`1件、`16209／津幡町`3件、`16210／金沢市`1件）。原本の県名欄は「石川県」のまま。
- 同じJCODEが複数名称に対応するものは11種類、同じ名称が複数JCODEに対応するものは14種類。例えば`17201`に金沢市、白山市、野々市町、津幡町、内灘町が対応している。
- 旧自治体名**「野々市町」11件**が原本に残る。2011年の市制施行後の現行名で自動上書きせず、原本を保持。
- 47組合せすべてを研究台帳の派生件数として保持し、現行市町村別統計・水稲統計・土地被覆へのコードJOINは保留。

## GUN（郡）と地名の不整合

- 郡名空欄434件、郡名付き196件。郡別の原本件数：羽咋郡73、鳳珠郡59、河北郡31、鹿島郡18、能美郡10、石川郡5。
- 郡名×市町村名の**29組合せ**を地目別に固定。
- **`17384／中能登町／羽咋郡` 1件（田）**の組合せを要照合として記録。中能登町は通常鹿島郡に属するため、原本の郡名の整合に疑義がある。ただし、境界年代やデータ加工過程を検証するまでは、勝手に「鹿島郡」へ補正しない。
- `石川郡／野々市町`5件も、旧行政名称として原本のまま保存する。郡名の正規化結果を別途作る場合は、原本値と修正履歴を両方残す。

## 追加ファイル

- `research/p44-ishikawa-soil-shapefile-source-v1.json`：原本と全7ファイルのSHA・図形630件・地目4区分・47 JCODE×名称・29 郡×名称、旧名称と不整合を記録。
- `scripts/p44-ishikawa-soil-audit.py`：元ZIPを手元に置く環境でZIP SHA・全7 SHA・SHPヘッダー・DBF630件を再照合する`verify`。公開CIでは元ZIPを公開しないため、台帳のみの`audit`。
- `src/gx-ishikawa-soil.js`：GX Data Atlasで石川県を選んだときに、地目別カード、県外JCODE注意、郡名別集計、29 GUN×名称と47 JCODE×名称を表示。
- `tests/p44-ishikawa-soil-gis.test.mjs`：ZIP/台帳由来の件数、県外JCODE、旧名称、郡名の疑義、変造検知、先行15都道県の表示互換性を固定。

元ZIPがある環境で原本再検証：

    python3 scripts/p44-ishikawa-soil-audit.py verify '/local/private/石川県.zip'

公開CIで元ZIPを持たない台帳検証：

    python3 scripts/p44-ishikawa-soil-audit.py audit
    node tests/p44-ishikawa-soil-gis.test.mjs

公開CIのauditは原ZIPの全バイト照合の代替ではない。初回受入時には別途アップロード元ZIPから構成ファイルのSHA・全図形・属性を確認している。
