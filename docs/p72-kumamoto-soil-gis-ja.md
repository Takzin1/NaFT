# NaFT P72｜熊本県農耕地土壌GIS：原本監査・行政属性の要照合・安全な再利用

## 原本と公開範囲

2026-11-10提供 `熊本県(1).zip`（12,144,480 bytes、SHA-256 `313aa016909916a4400d209c297120eb8b719e94264c8263c7671dbecccecb78`）。`k43熊本県` 内にDBF/PRJ/SBN/SBX/SHP/SHP.XML/SHXの7ファイル（展開計18,977,756 bytes）。DBF・SHP・SHXは**1,573件**で一致し、SHP/SHX全件のレコード番号・オフセット・長さも一致。ESRI POLYGON（shapeType 5）、GCS_JGD_2000。原本XML作成日2017-01-17。

出典候補：農研機構「日本土壌インベントリー」 https://soil-inventory.rad.naro.go.jp/download5.html 。公式配布ZIPとのバイト単位の同一性、配布元認証、著作権・再配布許諾は未確認。**元ZIP・SHP・DBF・個別地物座標は公開GitHubに置かず**、原本と構成ファイルのSHA-256、非座標の派生集計、検証方法だけを保持する。

## 行政属性の品質

- 原本DBFの全1,573件の県名 `KEN_1` は熊本県、`SICHO` は全件空欄。市町村名45種類、JCODE47種類、JCODE×名称119組、GUN×名称74組。
- **福岡県系JCODE（40系）15件**：`40202`（南関町・荒尾市）、`40210`（和水町・山鹿市）。県内コードへ無断で修正しない。
- **JCODE 29種類が複数市町村名、自治体名38種類が複数JCODEに対応**。現行自治体統計と自動JOINしない。
- **郡名GUNが779件空欄**。うち同じ市町村名の郡名記載レコードが別途あるものが132件。郡名の推測補完はしない。
- 複数の非空郡名に対応する自治体名6種類：御船町（上益城郡・阿蘇郡）、甲佐町（上益城郡・下益城郡）、山都町（上益城郡・下益城郡・阿蘇郡）、球磨村（球磨郡・芦北郡）、益城町（上益城郡・菊池郡・阿蘇郡）、西原村（菊池郡・阿蘇郡）。
- **「芦北郡」は熊本県内の原本郡名**で56件。誤って県外の郡名と判定しない。

## 公開監査とローカル原本再検証

- `research/p72-kumamoto-soil-shapefile-source-v1.json`：原本ZIPと7ファイルのバイトSHA-256、地目・行政属性の派生集計、郡名多対多・コード要照合を記録。
- 公開CI：`python3 scripts/p72-kumamoto-soil-audit.py audit` と `node tests/p72-kumamoto-soil-gis.test.mjs`。原本ZIPは公開CIに置かず、台帳の一貫性を監査する。
- 許諾済みローカル環境：`python3 scripts/p72-kumamoto-soil-audit.py verify '/private/熊本県(1).zip'`。ZIP全バイト・7ファイルのSHA-256、SHP/SHX全1,573件、DBF全行CP932属性・行政属性集計・土壌分類を再現監査する。
- GX Data AtlasでprefCode `43` を選ぶと地目別件数、JCODE×名称119組、GUN×名称74組と要照合情報を表示する。

**科学・制度上の制限**：ポリゴン数は農地面積ha、土壌炭素量、CH₄/CO₂e削減量、認証済み炭素クレジット発行量ではない。圃場単位のMRVには適法な境界、時点・方法論の整合、一次証拠、HITL、第三者検証が別途必要。
