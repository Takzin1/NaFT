# NaFT P48｜長野県農耕地土壌GIS 原本検証・行政コード・郡名の照合保留

ユーザー提供`長野県.zip`から全7構成ファイルを展開し、原本SHA-256、SHP/SHX/DBF全2,518件、JCODE・市町村名・郡名の属性を確認した。**原本の異常に見えるコードや郡名は無断で修正しない。**

## ZIP来歴・検証可能な仕様

- ZIPサイズ：**12,941,155 bytes**。SHA-256：`1760eeddfc65c44240dbb84ee221925c38814a705b65fe97cc6aeb4068b386fd`。
- 元ZIPは日本語ファイル名がCP932で符号化されている。内部フォルダは`k16長野県`。dbf、prj、sbn、sbx、shp、shp.xml、shxの計7ファイルで、解凍総量は**21,293,734 bytes**。各ファイルのサイズ・SHA-256を研究台帳に固定。
- Shapefile POLYGON（shapeType=5）、GCS_JGD_2000。SHP・SHX・DBFは2,518件で一致。すべての図形・属性をPyShpで初回走査。DBFヘッダは2,518レコード、353 bytesヘッダー、1,098 bytesレコード。
- bbox（経緯度）：`[137.4472894680439,35.203588111443956,138.70208377936234,37.00325490200541]`。
- 原本の`KEN_1`は全件「長野県」、`SICHO`は全件空欄。原本XMLのメタデータ作成日は**2017-01-17**（農地の2026年現況を保証するものではない）。

## JCODE 82種類×市町村名77種類の対応不整合

- 原本JCODE・名称の実在組合せは**176通り**。
- 長野県「20」系以外のJCODEは**10ポリゴン・6組合せ**：**群馬県「10」系3件、新潟県「15」系2件、山梨県「19」系5件**。
- 42コードは複数市町村名に、55市町村名は複数JCODEに対応する。接頭2桁が県と一致しても、個々のコードを自治体の正規化済み識別子として扱うことはできない。
- 原本値を保持した状態で87種類などと誤表記せず、77名称と82コードを独立に計数する。別統計（e-Stat/JAXA/2024水稲統計等）との無検証JOINは保留。

## 郡名GUNの欠損・複数対応・県外名

- GUNは空欄**1,276件**、郡名付き**1,242件**、名称種類は空欄を含め18種類。
- 郡名×市町村名の組合せは**116通り**。
- **県外を示す郡名が5ポリゴン**：新潟県「中魚沼郡」2件（原本の栄村）、群馬県「甘楽郡」2件（佐久市）、群馬県「吾妻郡」1件（軽井沢町）。5件の原本のJCODE・地目区分を台帳に個別保存。原因は未検証。
- 同一市町村名で、空欄GUNと郡名付きGUNの両方が存在する**33組合せ・290ポリゴン**。これは市町村の郡所属を推定して原本へ補記する理由にはならない。
- 郡名が複数記録された名称は**長和町（小県郡・北佐久郡）、松川町（上伊那郡・下伊那郡）、池田町（北安曇郡・東筑摩郡）、栄村（下水内郡・下高井郡・中魚沼郡）、軽井沢町（北佐久郡・吾妻郡）**。歴史的経緯、国境・県境横断の図形処理、GIS属性の誤混入など、原因を推定だけで確定しない。

## NaFTへ追加する内容

- `research/p48-nagano-soil-shapefile-source-v1.json`：元ZIP・7構成ファイルのSHA、176コード組合せ・116郡名組合せ、5件の県外GUN詳細と290件の欠損、原本保全の方針。
- `scripts/p48-nagano-soil-audit.py`：CIでは研究台帳の整合性をチェック。元ZIPがある手元の環境では全バイト・DBF2,518件を読み直す`verify`で原本との照合が可能。
- `src/gx-nagano-soil.js`：GX Data Atlasで長野県を選択したときだけ地目カード、県外コード・郡名の注意、JCODE176行・GUN116行を表示。
- `tests/p48-nagano-soil-gis.test.mjs`：元ハッシュ、コードと郡名の不整合、原本集計の改変検知、既存19都道府県のUIへの回帰を監査。

公開CIでの台帳検証：

```sh
python3 scripts/p48-nagano-soil-audit.py audit
node tests/p48-nagano-soil-gis.test.mjs
```

オフラインでの原本完全再照合（元ZIPは公開GitHubに置かない）：

```sh
python3 scripts/p48-nagano-soil-audit.py verify '/private/local/長野県.zip'
```

**CIでのaudit成功は元ZIP全バイトの再検証を意味しない。** 受入時には元ZIPから直接図形・全属性・ハッシュを検証している。
