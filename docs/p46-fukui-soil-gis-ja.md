# NaFT P46｜福井県農耕地土壌GIS：原本510件と県外JCODE・若狭町の郡名揺れ

ユーザー提供`福井県.zip`を2026年11月に解凍・検査した結果を、NaFT GX Data Atlasの研究用土壌GISパネルに加える。**原本のJCODE・郡名GUN・市町村名は自動補正しない**。公開GitHubにコミットするのはハッシュと派生集計・検証コードのみ。

## 受入元ZIPと原本の仕様

- 元ZIP `福井県.zip`：**3,111,309 bytes**。SHA-256：`4c81e96c9a94f48990cd4ba8ba14cf44ce9fced90321cb30ca65f0dbc2ec5357`。
- 元ZIPのフォルダ名：`k21福井県`。構成7ファイル：`.dbf`、`.prj`、`.sbn`、`.sbx`、`.shp`、`.shp.xml`、`.shx`。総展開サイズ**5,089,966 bytes**。原本の各ファイルSHA-256は研究台帳に記録。
- Shapefileの形状型はPOLYGON（shapeType=5）、座標系はJGD2000（GCS_JGD_2000）。SHP、SHX、DBFは**510件**で一致し、全形状・全属性を受入時に読んで確認した。
- バウンディングボックス（経度・緯度）：`[135.45436972693855,35.38873158534855,136.69095552335563,36.288086622838335]`。
- DBF`KEN_1`は全510件で「福井県」、`SICHO`は全件空欄。XMLに記載されたメタデータ作成日は2017-01-17。これは2026年時点の農地現況の実証ではない。

土壌「群コード」16種類、「包括_統群」48種類。**ポリゴン件数は面積haではない**。農地筆数、耕作者数、CH₄実測値、土壌炭素量、CO₂e削減量、認証クレジットにも換算しない。

## 行政コード（JCODE）と市町村名

- 市町村名17種類、JCODE18種類、JCODE×市町村名**31組合せ**。
- 福井県でなく石川県を示す「17」系の`17206／あわら市／樹園地`が**1ポリゴン**含まれる。原因は未確認であり、誤記と決めつけず原本属性のまま要照合とする。
- **8 JCODE**が複数市町村名に、**9名称**が複数JCODEに対応する。全てが5桁コードで県接頭辞が正しくても、自治体別の自動JOINは安全とは言えない。
- `research/p46-fukui-soil-shapefile-source-v1.json`に31組合せとそれぞれの田・普通畑・牧草地・樹園地の件数、異常を記録。元GISの座標を検証しないまま現行自治体コードへ自動変換しない。

## 郡名（GUN）の不足と揺れ

- GUN空欄**333件**、郡名付き**177件**。内訳：三方上中郡30、三方郡32、丹生郡26、今立郡17、南条郡18、吉田郡20、大飯郡34。GUN×市町村名**22組合せ**。
- **若狭町**のGUNは同じ原本内で`三方上中郡／若狭町`30件、`三方郡／若狭町`2件（田1・樹園地1）、空欄3件に分かれる。これらを元のまま保持し、「郡名揺れ・要照合」と表示。
- 同じ市町村名に郡名付きレコードもあるのにGUNが空欄：**南越前町3件、永平寺町8件、若狭町3件、越前町6件＝20件**。空欄のまま保持し、郡名の強制補完をしない。
- 公的な市町村・郡境界、原GISの記録年代、土地ポリゴン位置との照合が終わるまで、郡別統計を確定扱いしない。歴史上の区分かデータ混入かをZIPだけで断定しない。

## 公開ファイルと検証手順

- `research/p46-fukui-soil-shapefile-source-v1.json`：原本ハッシュ・全ファイルハッシュ・地目別件数・JCODE31組合せ・GUN22組合せ・郡名空欄20件と揺れ2件。
- `scripts/p46-fukui-soil-audit.py`：標準ライブラリのみでメタデータ監査、および元ZIPを手元に保持する場合はそのバイトSHA、7ファイルSHA、図形・DBF全510件、JCODE・GUNを再検証。
- `src/gx-fukui-soil.js`：GX Data Atlasで福井県（都道府県コード18）を選択したときだけ、地目カード・行政コード警告・郡名別内訳・元のJCODE/GUN組合せ一覧を表示。
- `tests/p46-fukui-soil-gis.test.mjs`：原本ハッシュと派生集計、県外JCODE、若狭町の複数郡名、郡名空欄、改ざん検知、既存17都道県のUI互換を検証。
- `naft-app.html`、`src/gx-data-explorer.js`、`tests/run.sh`で統合。

原本ZIPがある閉じた環境での検証：

    python3 scripts/p46-fukui-soil-audit.py verify '/local/private/福井県.zip'

原本ZIPを公開しないGitHub CIでの検証：

    python3 scripts/p46-fukui-soil-audit.py audit
    node tests/p46-fukui-soil-gis.test.mjs

**CIの`audit`成功は、CI環境が原ZIPを再取得してハッシュを比較したという意味ではない。** 本件の元ZIPはユーザーが提供したファイルを直接検査している。

## 出典と利用可能性の制約

公開元候補は農研機構（NARO）「日本土壌インベントリー／農耕地包括土壌図」：https://soil-inventory.rad.naro.go.jp/download5.html 。**公式配布の福井県ZIPとのSHA一致および今回のZIPへの利用許諾は未確認**。元GIS図形、DBF、Shapefile ZIPはライセンス確認までGitHubへ複製しない。

当該データのみをもとに農地面積、CH₄実測、土壌炭素削減、tCO₂e、J-クレジット認証済みの排出削減を推論しない。
