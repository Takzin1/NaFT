# NaFT P54｜京都府農耕地土壌GIS：原本属性監査

ユーザー提供の `京都府.zip` を受け入れ、原本の全7構成ファイルとShapefile/DBFの**969ポリゴン**を検査。原本コード・郡名・土壌分類の不整合は推測で補正せず、全国GX Data Atlasで「要照合」として公開する。

## 原本来歴・再現可能性

- 提供ZIP：**3,960,656 bytes**。SHA-256：`f5440640ef355f37e6bd4ee67f2039521407f252398fdfdabcb3b5fbf221bf9a`。
- 7メンバー：`k26京都府` フォルダの `.dbf` / `.prj` / `.sbn` / `.sbx` / `.shp` / `.shp.xml` / `.shx`。非圧縮合計6,770,512 bytes。個別ハッシュ・バイト数は研究台帳に記載。
- 形状：POLYGON (shapeType 5)、GCS_JGD_2000、bbox `[134.8673268777947,34.70883381293244,136.04693401420027,35.7663518420321]`。SHP・SHX・DBFの各969件が一致。
- 全件 `KEN_1=京都府`、`SICHO`は空欄。原本XMLメタデータ作成日2017年1月17日。
- 原本候補：農研機構の「日本土壌インベントリー」（ https://soil-inventory.rad.naro.go.jp/download5.html ）。公式の京都府ZIPとのハッシュ一致・個別の再配布権利は**未確認**。原本GISバイナリを公開GitHubに複製しない。

土壌群コード18種類・詳細分類64種類（空欄の1カテゴリを含む）。**京丹波町／JCODE26407／船井郡／田1件**（原本DBFレコード番号228、0始まりindex 227）は、`包括_統群`・`統群コード`・`亜群コード`・`群コード`の4項目がすべて空欄。推測補完禁止。

## JCODE・名称の照合

- `SIKUCHOSON`（市区町村名）は33種類。JCODE37種類、JCODE×名称は**75組合せ**。
- 京都府「26」以外のJCODEが**10ポリゴン**：滋賀県「25」系7、三重県「24」系2、福井県「18」系1。原本属性を改変せずに保持。
- **23種類のJCODEが複数名称**に、**26種類の名称が複数JCODE**に対応。一意の自治体コードと仮定して現行統計へJOINしない。

## GUN（郡名）と地目の照合

- GUN空欄742件、記載227件。郡名×名称は**44組合せ**。
- `舞鶴市／大飯郡` は**田1件**（原本JCODE18481）、福井県系コード・郡名の混在がある。
- `和束町／綴喜郡` は**樹園地1件**（JCODE26344）。同じ和束町の原本には`相楽郡`の記録もある。単純な郡名正規化は行わない。
- 同じ自治体名の別レコードには郡名が存在するにもかかわらず、GUN欄が空欄のものが**88件**。これは一律に欠損や誤記と断定しない。

## 実装・監査・テスト

- `research/p54-kyoto-soil-shapefile-source-v1.json`：ZIPおよび全7ファイルのSHA-256とサイズ、地目・JCODE75組合せ・GUN44組合せ・疑義を保存。
- `scripts/p54-kyoto-soil-audit.py`：Python標準ライブラリのみ。公開CIは`audit`で原本台帳と派生件数の内部整合を確認。元ZIPを持つ環境では`verify PRIVATE_ORIGINAL.zip`で全7ファイルのハッシュ、SHP/SHX、DBF969行と土壌分類欠損1件を再検証。
- `src/gx-kyoto-soil.js`：GX Data Atlasで京都府（26）選択時の地目・JCODE・GUN別表示。原本異常値の注意書き付き。
- `tests/p54-kyoto-soil-gis.test.mjs`：データ改変や原本疑義の脱落を防ぐ専用テストと既存25都道府県の表示回帰。
- `naft-app.html`、`src/gx-data-explorer.js`、`tests/run.sh`から機能を有効化。

公開CIでの検証：

```sh
python3 scripts/p54-kyoto-soil-audit.py audit
node tests/p54-kyoto-soil-gis.test.mjs
```

手元に原本ZIPがある場合の再検証：

```sh
python3 scripts/p54-kyoto-soil-audit.py verify '/private/path/京都府.zip'
```

`audit`の成功は**生ZIPのCI内での再検証ではない**。元ZIPを保有する受入時のローカル検証結果と、公開GitHubにコミットした派生集計・ハッシュの監査を区別する。

## 科学的制約

ポリゴン件数は面積ha・筆数・CH₄の実測・土壌炭素量・CO₂e削減量・J-クレジット認証量を意味しない。土壌区分の由来年代、行政区境界、公式コード表を未照合のまま2024年水稲統計やJAXAデータとの自動JOINを行わない。
