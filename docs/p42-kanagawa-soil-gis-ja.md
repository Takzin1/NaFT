# NaFT P42｜神奈川県農耕地土壌GIS：関東7都県目の原本監査とコード・郡名の保留

2026-11-09、ユーザー提供`神奈川県.zip`を解凍し、7構成ファイルのSHA-256・形状・属性1,060件を検査した。NaFTが実装した関東7都県の最後の県。**原本JCODE・郡名GUNに不整合があり、現行自治体別の確定統計や外部統計との自動結合には使わない。**

## 受入元ZIPの来歴・ハッシュ

- 元ZIP：**2,684,622 bytes**、SHA-256 `997a9ceac06fd70c2223cfb086f4aebc9ad38a74070fa43fe7bf80797ad84282`。
- ZIP内フォルダ：`k14神奈川県`。Shapefile関連ファイル`k14神奈川県.dbf`、`.prj`、`.sbn`、`.sbx`、`.shp`、`.shp.xml`、`.shx`の7ファイル。元ZIPの日本語名はCP932で符号化。展開後計**5,082,502 bytes**。各ファイルのSHA-256は研究台帳に個別記載。
- ESRI POLYGON（shapeType=5）、JGD2000（GCS_JGD_2000）。SHP・SHX・DBFはすべて**1,060件**、全ての形状をpyshpで走査。DBFの列構成・件数を別途監査スクリプトで検証できる。
- bbox（経度・緯度）：`[139.0015703824738,35.132446443281,139.70958906726077,35.66027242266548]`。
- `KEN_1`は全件神奈川県、`SICHO`は全件空欄。XMLメタデータ作成日は2017-01-17であり、地図の2026年現況調査日ではない。
- 公開配布元候補は農研機構（NARO）「日本土壌インベントリー／農耕地包括土壌図」https://soil-inventory.rad.naro.go.jp/download5.html 。**公式サイトの神奈川県ZIPとのバイト単位のSHA一致は未確認**。これに伴い本ZIPへの具体的な適用ライセンス・再配布許可は`NOT_VERIFIED`のまま記録。

## 市区町村名と行政コードの不整合

- `SIKUCHOSON`の名称は**52種類**（横浜市・川崎市・相模原市の行政区も含む）、JCODEは**55種類**。組合せは**128通り**。
- 神奈川県「14」ではなく東京都「13」で始まるJCODEが**18ポリゴン・6組合せ**含まれる（主に多摩地域との接境部を含む原本属性だが、これが混入した理由は未確認）。例：`13209／麻生区`が7件、`13225／麻生区`が4件。
- 36種類のJCODEは複数名称に、39種類の市区町村名は複数JCODEに対応している。原本の値を無断で補正せず、**128組合せをそのまま台帳化**。
- JCODEをキーとして2024年水稲統計、土地被覆、自治体統計に自動JOINすることは禁止する。GIS位置・行政境界・コード年代・原データ加工履歴を別途照合する。

## 神奈川県特有のGUN（郡名）疑義

- GUN空欄885件、郡名付き175件。内訳：**足柄上郡67件、中郡46件、高座郡22件、足柄下郡18件、愛甲郡18件、三浦郡4件**。
- GUN×名称の**63組合せ**を地目4種別に固定。
- **`JCODE 14342／中井町／GUN 中郡`が2件（田1・樹園地1）**。中井町は足柄上郡として知られるため、原本の属性の整合が疑わしい。この値は原本どおり保存し、UIで「郡名に疑義・要照合」と表示。行政郡境界を用いて検証するまで、勝手に「足柄上郡」へ書き換えない。
- GUNとJCODEを同時に無条件で正規化・結合すると、原データの問題を隠す可能性がある。**検証結果は別バージョンの修正履歴として残す**。

元ZIPのあるローカル環境で完全検証：

    python3 scripts/p42-kanagawa-soil-audit.py verify '/local/private/神奈川県.zip'

    python3 scripts/p42-kanagawa-soil-audit.py audit
    node tests/p42-kanagawa-soil-gis.test.mjs
