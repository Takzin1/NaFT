# 技育展2026｜NaFT カーボンクレジット版アニメーション（78秒）

**主題：水田の温室効果ガス削減活動を、検証可能なカーボンクレジット申請用の記録につなぐ。**

研究開発者・審査員に向けて、水田の中干しを題材に、農家の活動記録、圃場情報、証憑、方法論変更への対応を、平易な図解で伝える。

## 基本仕様

- **78秒、1280×720、16fps、H.264 / AAC、MP4**。日本語焼き込み字幕＋オリジナルBGM。**人間のナレーション音声なし**。
- **全編オリジナル模式図**。実際のNaFT画面操作の収録ではない。
- 動画本体は会話内で制作。GitHubには絵コンテと機械可読SRTを保管（MP4は本PRに含まない）。
- 水田・中干しは**カーボンクレジットMRVの業務を理解するための具体例**。100件の数値は現行GitHubデモの**独立した合成実験**。

## 絵コンテ

| 秒 | カーボンクレジットに即した画面 | 伝える内容 |
|---|---|---|
| 00–10 | 水田、中干し、農家。活動記録の吹き出し | 水田で温室効果ガス削減活動を実施しても、クレジット審査には記録と根拠が必要 |
| 10–21 | 農地→中干しの記録、圃場情報、関連資料→NaFT | 様々な証拠を案件に紐づけて管理する |
| 21–31 | 従来ルールv1→新しい**合成ルール**v2。特定条件へのセンサー記録追加 | 新たな証憑要件が生じた時の例（**実制度改定ではない**） |
| 31–50 | 100枚の案件カードが70枚と30枚に分離 | 合成100件のうち70件は影響なし、30件のみ要再検証 |
| 50–60 | 30件が15件（記録あり）／15件（記録不足）へ動く | 15件は自動再評価、15件は証憑不足で停止。自動再評価≠承認 |
| 60–70 | 旧版で確認済みだった判断に失効の斜線 | 入力・ルールが変わると、以前の人間判断を再利用しない |
| 70–75 | 水田の活動→NaFT→人が審査 | 証拠整理・依存関係追跡はNaFT、例外と最終判断は人間・制度側 |
| 75–78 | NaFT・技育展日本語デモ・QRコード | 審査員に動作デモを促す |

## 審査員向けの一文

> **カーボンクレジットを生む活動の「証拠」を、ルール変更後も追跡・再検証できるようにする。それがNaFTです。**

## 科学的・制度的な境界

- 水田の中干しの実際のJ-クレジット審査要件を、動画が網羅または実装しているとは主張しない。
- 実験の数値は **NAFT-SYNTHETIC@1 → @2** の合成版変更から計算：standard 70件 / intensive（sensorなし）15件 / intensive_complete（sensorあり）15件。
- v2でセンサー証憑要件を追加するのは **合成方法論の仮想設定**であり、J-クレジットのAG-005公式改定ではない。
- 100件中70件が影響なし・30件が要再検証という比率は、**合成fixtureの構成によるもの**。実務での70%省力化や、制度受入れ、発行実績、排出削減量の実証ではない。
- AG-005の最新正式版をNaFTが完全実装済みとは扱わない。正式認証、クレジット発行は行わない。
- この動画の図解は研究上のアーキテクチャ説明であり、実際のブラウザ録画ではない。
