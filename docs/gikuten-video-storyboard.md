# 技育展向け紹介動画｜NaFT 85秒版（日本語）

## 目的
審査員がNaFTの研究課題・変更影響解析・人間判断の境界を約85秒で理解できるよう、図解字幕入りの紹介動画を作成する。

**動画形式**：1280×720 / 24fps / H.264 + AAC / 約85秒。オリジナルBGMと日本語字幕あり。現時点では**日本語ナレーション音声なし**。

**注意**：UI風シーンは「模式図」であり実画面の操作録画ではない。ソフトウェアの計算結果は現行 `src/reviewer-demo.js` の合成入力・解析と整合するよう構成している。動画MP4自体は本PRには含まれない。

## 絵コンテ・読み上げ原稿

| 時間 | シーン | ナレーション原稿 |
|---|---|---|
| 00–08 | 課題提起 | ルールが変わるたび、すべての証憑を確認し直す。その負担を変えたい。 |
| 08–17 | 問題の構造 | 方法論や現場記録、センサーデータ、人の判断。更新されたとき、何が影響を受けるかを追うのは簡単ではありません。 |
| 17–26 | コアアイデア | NaFTは、変更点と依存関係を照合し、必要な検証対象を根拠とともに選び出します。 |
| 26–35 | ブラウザの模式図 | ブラウザで百件の合成データを解析する、研究用のデモを用意しました。 |
| 35–46 | 100件の解析 | この合成実験では、百件のうち三十件が再検証対象、七十件が影響なしでした。ただし、業務の七十パーセント削減を意味しません。 |
| 46–56 | 15件＋15件 | 再検証対象のうち十五件は自動再評価。残る十五件はセンサー証憑が不足するため、処理を止めます。 |
| 56–66 | 人間判断の失効 | さらに、入力や方法論の版が変われば、以前の人間判断を使い回さず、再確認を求めます。 |
| 66–76 | 自動化・人間の境界 | NaFTは、証憑の整理、決定論的な評価、依存関係の追跡を担います。例外判断や最終確認は人間の役割です。 |
| 76–85 | 体験導線 | 技育展向け日本語デモを公開しています。ぜひ、ブラウザで確かめてください。 |

## 技術・制度上の表現ルール

- 合成データの構成：標準条件70件、追加条件かつセンサーなし15件、追加条件かつセンサーあり15件。
- 解析結果：変更候補100件、再検証30件、影響なし70件、再評価15件、証憑不足15件。これらは**実環境での削減効果・精度・費用削減率ではない**。
- 合成版 `NAFT-SYNTHETIC@1 → @2` の差分デモであり、AG-005の公式制度改定の検証とは明確に区別する。
- 正式認証、現行方法論適合、実地での有効性を保証しない。
- 数値・方法論の説明を修正する場合は `src/reviewer-demo.js` と `docs/gikuten-demo.md` を先に確認する。
