# NaFT P39｜群馬県農耕地土壌GIS原本受入とJCODE・市町村名不整合の監査

2026-11-09、ユーザー提供 `群馬県.zip` を受入し、原本ZIPおよび7構成ファイルのハッシュ、SHP・SHX・DBFの全1,331レコードを照合。群馬県を北海道・東北・茨城・栃木・埼玉に続く11都道県目の研究用データとしてGX Data Atlasへ追加した。

## 原本仕様・固定ハッシュ

- 元ZIP：9,054,377 bytes、SHA-256 `b0e17480fb6e63a9d06282021bdf4cb9d8370d1d9609395b23ee475eed609596`。
- 内部CP932日本語名：`k10群馬県/k10群馬県.dbf`、`.prj`、`.sbn`、`.sbx`、`.shp`、`.shp.xml`、`.shx`（計7ファイル）。展開後合計14,540,632 bytes。各ファイルSHA-256を台帳に固定。
- ESRI POLYGON（shapeType=5）、JGD2000（GCS_JGD_2000）、SHP・SHX・DBFすべて1,331件。pyshpにより全1,331形状と属性を読み取り済み。
- bbox：[138.39759594568946,36.062419709071186,139.65816954918944,36.86534968788782]。
- 県名フィールドKEN_1は全件「群馬県」。SICHOは全件空欄。土壌「群コード」13種類、「包括_統群」71種類。
- XMLメタデータ作成日は2017年1月17日。これは原本の作成年代を示す手がかりで、現況作付・現行行政境界の正当性を証明しない。

## JCODEと市町村名の不整合：未解決として保存

- 市町村名35種類、JCODE38種類、コードと市町村名の組合せ94通り。確定的な市町村単位の集計には使用しない。
- KEN_1が群馬県のデータに、栃木県を示す「09」で始まるJCODEが**6組合せ・24ポリゴン**存在する。コードは09202、09203、09204の3種類。例：09202／太田市、09202／桐生市、09203／板倉町。
- 原本の20種類のJCODEが複数の市町村名に対応。30種類の市町村名が複数のJCODEに対応。群馬県「10」系のコードにも多重対応がある。
- 行政コードがその市町村の位置・管理区域を正しく示していると仮定しない。値を無断で置換・合算・削除せず、94組合せを研究台帳と画面に原本どおり保持する。
- 正規化する場合は、原本の形状位置、公的行政境界、各時点のコード台帳を突合し、修正点と根拠を版付きで記録してから新バージョンへ移す。

## 出典候補、ライセンスと科学上の境界

- 配布元候補は農研機構（NARO）「日本土壌インベントリー／農耕地包括土壌図」：https://soil-inventory.rad.naro.go.jp/download5.html
- このユーザー提供ZIPと公式配布ZIPとのバイト単位・SHA-256照合は未実施。元データの実際の再配布許諾がこのZIPへ適用できるかも未確認。**権利確認できるまで生のShapefile・DBF・ZIPを公開GitHubに置かない。** 原本ハッシュと派生集計のみ公開。
- 本GISだけで正式な農地面積、CH₄排出量、CO₂e削減量、J-クレジット等の認証済み数量を算出しない（official_credit_tco2e=null）。
- 無検証の2024年水稲統計、JAXA土地被覆等との行政コードJOINを行わない。

## NaFTへ追加したファイル

- `research/p39-gunma-soil-shapefile-source-v1.json`：元ZIP・構成7ファイルのSHAとサイズ、bbox、地目4区分、94組合せ、県外JCODE・多重対応の原本台帳。
- `scripts/p39-gunma-soil-audit.py`：Python標準ライブラリによる独立再検証。原本ZIPがある場合は全7ファイルSHA・SHP/SHX・DBF全件と集計を確認する `verify`、原本を保存しない公開CIでは派生レジストリ `audit` のみ。
- `src/gx-gunma-soil.js`：GX Atlasの「群馬県（10）」で地目別カード・94組合せ表・未解決JCODE警告を表示。
- `tests/p39-gunma-soil-gis.test.mjs`：原本台帳、異常コード、地目・94組合せの整合、UI県コード選別、既存10都道県の表示維持をチェック。

元ZIPの全バイト再検証：

    python3 scripts/p39-gunma-soil-audit.py verify '/private/local/群馬県.zip'

公開CI（原本ファイルのバイト照合は行わない）：

    python3 scripts/p39-gunma-soil-audit.py audit
    node tests/p39-gunma-soil-gis.test.mjs

GitHub CIの `audit` 成功は元ZIPの全バイト一致を意味しない。ZIPと構成ファイルのハッシュ、および全1,331件の属性は受入時のローカル環境で検証した。
